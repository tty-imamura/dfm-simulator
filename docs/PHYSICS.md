## 2. 公理系 (A1〜A13)

記号: 質点 i は質量 m_i、位置 **r**_i、速度 **v**_i、スピン s_i(符号付きスカラー、z軸まわり角速度)を持つ。
2次元平面でシミュレートする。半径 R_i = r_R·√m_i(2次元円盤。明示半径指定時は R_i = radiusScale·radius〔第38便〕)、
慣性モーメント I_i = ½·m_i·R_i²。
d_j = |**r** − **r**_j|、ε はソフトニング長(発散防止)。

- **A1(質点)** — 宇宙は有限個の質点の集合である。空間そのものは実体を持たない。
- **A2(相対空間)** — 空間座標は質点の相対配置からのみ定義される。絶対空間・絶対静止系は存在しない。
- **A3(決定力)** — 質点 j が点 **r** の空間座標に及ぼす「決定力」は
  w_j = m_j/√(d_j²+ε²)〔v1.2: Plummer 型に統一。ε→0 で原仮定 m/d に一致し、
  A6(E4 = G∇W)が有限 ε でも厳密に成立する(L5 解消)〕。
  遠方の大規模宇宙構造は一様等方な**背景決定力 D₀** として寄与する(補完①)。
  総決定力 W(**r**) = D₀ + Σ_j w_j(**r**)。
- **A4(局所フレーム)** — 各点の「空間の速度」**u**(**r**) は、決定力を重みとする各質点の運動
  (並進+スピン回転)の加重平均である。背景 D₀ の寄与は静止(遠方宇宙は平均して動かない)。
- **A5(慣性)** — 質点は**局所フレームに対する**速度 (**v**−**u**) を保とうとする。

- **A6(重力)** — 決定力の空間勾配が加速度を生む: **a** = G·∇D(**r**)。
  w ∝ m/d なので ∇w ∝ m/d² となり、**ニュートンの逆二乗則が自動的に再現される**。
- **A7′(時間)〔v1.4 改訂・原仮定者承認 2026-07-16〕** — 局所の固有時間の進みは、
  決定力が高いほど、また**共動フレームに対する運動が速いほど**遅い:
  dτ/dt = √( N² − A²·|**v**−**u**|²/c₀² )、 N = e^{−ψ}、 A = e^{+ψ}、 ψ = W_ext/K_t。
  弱場・低速では dτ/dt ≈ 1 − ψ − |**v**−**u**|²/(2c₀²) となり、旧 A7(1/(1+ψ))の
  一次形に運動項が加わった形になる。フレーム不在(W_ext=0)では運動は定義されず
  運動時間遅れも生じない(T1 と整合)。根号内 ≤ 0(局所光速超過)は非物理域。
- **A8(スピン引きずり)** — スピン s_j は周囲のフレームに回転成分 ω_j(d) を与える
  (レンズ=サーリング効果に相当。表面 d→0 で剛体回転 s_j に接続し、遠方で減衰)。
- **A9(熱=スピン)** — スピンの2乗がその質点の熱。温度は等分配則 ½I_i s_i² = ½k_B T_i より
  **T_i ≡ I_i s_i²(k_B = 1 のシミュレータ単位系。= ½ m_i R_i² s_i²)**〔v1.1: 旧略記
  T ∝ s²R² は質量因子を欠くため本定義で置換〕。
  接触時、並進運動の散逸分は接触摩擦を通じてスピンに変換される。
  また近接した質点同士のスピンは拡散し、十分な時間で平衡に達する。
- **A9′(温度の内部状態変数化)〔第36便・台帳4-51 — 原仮定者裁定の実装〕** —
  大きな粒子は小さな粒子の塊の近似である。温度は構成粒子のミクロで乱雑な内部回転であり、
  粒子ごとの内部状態変数 **T_int ≥ 0** として保持する(保有熱 E_int = cHeat·m·T_int)。
  マクロな spin は**コヒーレントな回転**であり温度ではない。冷たい高速回転体が急停止すると、
  その運動エネルギーは散逸(E9)を通じて T_int へ移り「熱い静止した粒子」になる。

  **A9(T=I·s²)は本則の暫定射影**であり、thermal:"spin"(既定)のサンプルで従来どおり有効。

- **A9″(内部温度=ミクロスピン分散)〔第64便・スケールの整理スプリント — 3外部分析の収束裁定〕** —
  A9′ の「ミクロで乱雑な内部回転」を統計量として正式化する。1個のシミュレーション粒子を多数の
  微小構成粒子の粗視化とみなし、各構成粒子の内部スピンを s_a = s_coh + δs_a と分解する
  (s_coh = 全体で揃ったコヒーレント回転 = 状態配列の spin/δs_a = 内部で乱雑に回る揺らぎ)。

  マクロ⇔ミクロの緩和時間)は帳簿設計を伴うため見送り — 変換経路は現行の4つ

## 4. 調整と補完(原仮定に対して設計者が追加・確定した点)

1. **背景決定力 D₀ の導入** — 「大規模構造に囲まれると安定」を定量化するパラメータ。
   これが無いと u の分母が 0 になり得る(質点が1個も無い点でフレームが未定義)。
   D₀→∞ でニュートンの絶対空間に、D₀→0 で完全な相対空間(マッハ原理)に漸近する。
2. **決定力の距離則の確定〔v1.2 改訂〕** — w = m/√(d²+ε²)(Plummer 型)。
   ∇w = −m·(**r**−**r**_j)/(d²+ε²)^{3/2} となり **E4 = G·∇W が有限 ε でも厳密に成立**する
   (v1.5 実装で統一、L5 解消。V9 で機械検証)。ε→0 で原仮定「決定力は m/d」に一致し、
   「引力はその微分」という原仮定と厳密に整合する。遠方漸近・d=0 の値(m/ε)は旧式と同一。
3. **スピン引きずりの減衰則** — ω_j(d) = s_j·(R_j/(R_j+d))^q、q=2 を既定とした。
   d→0 で剛体回転(表面速度 s·R)に接続し、遠方では ω·d ~ 1/d と減衰して重力(1/d²…積分的には
   ポテンシャル1/d)より短距離で効く。q はパラメータとして編集可能。
4. **エネルギー整合** — 「速度→スピン変換」は2次元円盤の接触摩擦インパルスとして実装する。
   これにより変換の**符号が自動的に正しく**なり(かすめる衝突は接触点の滑りを打ち消す向きの
   スピンを生む。ケプラー剪断下では全粒子のスピンが同符号に揃う)、T3 の整列が創発する。
   〔v1.1: 摩擦則の符号と作用線を A13/T7 に整合するよう改訂した。E9 参照〕
5. **時間の遅れの適用範囲** — 既定では (a) 各質点の固有時計の表示、(b) 光線の屈折(T5)に適用。
   物質の力学への適用(深い重力井戸内でスローモーションになる)はトグルで選択可とする
   (常時適用は数値コストと安定性の理由で既定オフ。補完としてここに明記)。
6. **保存則について〔v1.1 で改訂〕** — 旧版では「大域の運動量・角運動量は厳密には保存しない」
   としていたが、原仮定者の相互性公理 A13 により**厳密保存**へ改訂した(T7)。
   フレーム引きずり(E6′)は引きずった側への反作用を伴い、背景 D₀ との交換分は
   無限慣性リザーバへの移譲として帳簿づけされる。k_frame = 0 とおくと

#### 一様重力場 gravityX / gravityY〔v1.17〕
決定力勾配(E4)とは独立に、全自由粒子へ一様な外部加速度を加える:
v̇ᵢ += (gravityX, gravityY)。決定力 W には寄与しないため、時計(E7R)・光(E8R)・
フレーム引きずり(E6′)を一切歪めない。地上実験室(自由落下・対流・沈降)の
デモに使う。運動量・角運動量の変化は外場との交換としてリザーバ帳簿
(resP/resL)に記録され、恒等式 P + resP = 一定 は維持される(下記)。
D₀ が「遠方宇宙の背景決定力(マッハ原理的安定化)」を表すのに対し、
gravityX/Y は「局所的な外部場(地表重力など)」を表す — 役割が異なる。

### 保存量モニタと帳簿変数〔v1.1〕
- 系の保存量: **P** = Σ m_i**v**_i、 L = Σ m_i(**r**_i×**v**_i)_z + Σ I_i·s_i
- リザーバ帳簿: resP(背景・pinned へ移譲した運動量)、resL(同・角運動量)、
  radE(放射した累積エネルギー: 法線減衰の散逸 + E11 冷却 +〔v1.2・A12′〕接線摩擦の
  すべり散逸 + E10′ 同期散逸)、radL(E11 が持ち去った角運動量)
- 検証恒等式(T7): **P** + resP = 一定、 L + resL + radL = 一定(境界反射なしのとき)

### 光学輸送(体積吸収・赤化・散乱)〔第82便 2026-08-06 — v1.38-b1・opt-in〕

E8R は「光がどう曲がるか」(屈折 n_eff=e^{2ψ} と決定フレーム随伴)だけを決め、
**光がどれだけ減るか**は扱っていなかった。第82便 A で、光線積分器の経路に沿って
**光学的深さ**を積む観測層を opt-in で追加した。**力学・固有時計 τ・既存の減光
(lightSweep=自星の光の掻き出し)は 1 bit も変えない** — 効くのは光線(rays)と
その表示(減光・拡散光・スペクトル読み口)だけである(QA `optics.dynamics-invariant`)。

**式**

- 体積吸収: `dτ_ref = kAbs · ρ_local(r) · ds`(ds は光路長 = 積分刻み dl)
- 波長依存: `τ(λ) = τ_ref · (λ_ref/λ)^pAbs`、透過率 `T(λ) = e^{−τ(λ)}`、λ_ref = 550 nm
- 局所質量核(**コンパクト台**):
  `ρ_local(r) = Σ_j m_j·(3/(π a_j²))·(1 − (d_j/a_j)²)²`(`d_j < a_j` のみ)、
  `a_j = K·max(R_j, ε)`、K = 4、∫ρ_local dA = Σ m_j に規格化

**なぜ決定力 W をそのまま使わないか**: W = Σ m/√(d²+ε²) は 1/d で無限遠まで伸びるため、
「雲の外」が定義できず、どんなに遠い光線にも有限の吸収が乗ってしまう。体積吸収は
**台のある核**を別に立てる。台の外はちょうど 0(境界で値・1階微分とも 0 に接続)なので、
どの天体の台にも入らない光線の τ は**厳密に 0** になる。

**台係数 K = 4 の較正**(実測 `tests/exp-4-83.mjs` case F)。粒子間隔を s、粒子半径を R として:

- 滑らかな(粒状性の小さい)吸収体には台が間隔の 1.5 倍程度必要: `a ≳ 1.5·s`
- 粒子が接触斥力(E9)で反発しない散逸のない雲であるには `s > 2R`
- 両立条件は **K > 3**。実測の粒状性(一様円盤の解析柱密度 τ_an=kAbs·Σ·2√(R_c²−y²) からの
  相対 RMS)は K=1.5→6 で 0.34→0.12 と単調に下がり、K=4 で 0.16。台のはみ出し
  (光学半径の膨張)は間隔側で決まり K にはほぼ依らない(相対はみ出し ≈ 2.7/√n)ため、
  下限 3 に余裕 33% を見た **4** を採る。ε 下限は「吸収核は力の緩和長より鋭くならない」の意味論

**散乱(初期スコープ)**: `fScat` は減衰分のうち吸収体の**拡散光**として描画に足し戻す割合。
光線の分岐(多重散乱)は**しない** — 描画層だけの効果で、τ も力学も変わらない。

**E8R 屈折との関係**: 屈折(曲がる)と吸収(減る)は独立な機構で、同じ経路積分の上に載る。
吸収体は光線源のしきい質量 `m ≥ (α_min/4)·Kt·max(R,ε)`(第45便)とは**別集合**で、
質量を持つ全粒子が吸収体になる。デモ 🌆reddening は雲の 1 粒 m=1 がしきい値 20 を大きく
下回るので、**曲がらずに減るだけ**の純粋な吸収体になっている。光線キャッシュ(v1.22)は
kAbs>0 のとき吸収体の配置もキーに含める(既定 kAbs=0 ではキーは 1 文字も増えない)。

**透過後スペクトルの読み口**(表示・診断のみ): スペクトル表示(🌈)に
「源スペクトル × T(λ)」を橙の輪郭バーで、透過率 T(λ) そのものを橙の折れ線で重ねる。
このグラフの横軸 λ=b_m/T は**モデル単位**で、光線表示の nm(λ_ref=550nm 基準)とは
別の尺度なので、τ_ref は「表示帯域の中央波長 λ_c での光学的深さ」と読み替える
(主張の対象は帯域内の**相対**赤化 = 形であり、絶対値の基準は光線側にある)。
輝度が λ^{−pAbs} で落ちる源(pRad = pAbs)では透過後の輝度は u·e^{−τ_ref u}
(u=(λ_c/λ)^pAbs)となり、ピークは **λ_peak = λ_c·τ_ref^{1/pAbs}** へ動く(実測 5.09 倍)。

**パラメータ**(いずれも physics の任意キー・UI スライダーは持たない = プリセット JSON 専用)

| キー | 既定 | 値域 | 意味 |
| --- | --- | --- | --- |
| `kAbs` | 0 | 0〜10 | 吸収強度。0 で光学輸送は完全に OFF(光線ループに追加演算を持ち込まない) |
| `pAbs` | 4 | 0〜8 | 波長依存指数。4 でレイリー類似(青が強く減衰)、0 でグレー吸収(赤化なし) |

### 創発水準(E0〜E3)と標準試験〔第82便B 導入 → 第83便A 標準試験化〕

サンプルの中には「初期条件に置いたものがそのまま見えているだけ」のものと、
「局所則だけから、置いていない構造がひとりでに立ち上がるもの」がある。両者を
**見た目**で区別することはできない。適当な seed をいくつか試して**それらしく見えた1本**を
展示すれば、静止画でも動画でも創発と見分けがつかないからである。この節は、その区別を
**宣言(E水準)**と**実測(標準試験)**の二本立てで機械化するための正本である。

#### E水準 — 何を主張しているかの宣言

`emergence:"E0".."E3"` はプリセットの宣言専用メタで、**物理には一切影響しない**
(`validatePreset` は有効値を保持し未知値を警告つきで削除するだけ。QA `emergence.tag`)。
自動判定はせず、下の標準試験の実測結果に基づいて人が宣言する。

| 水準 | 意味 | 要求される実測 |
|---|---|---|
| **E0** | 規定 — 創発の主張をしない | なし(初期条件・外部規定で構造がほぼ決まっている) |
| **E1** | 外部駆動下の自己組織化 | 駆動(伝熱壁・レール・pinned 等)がある系で、局所則から秩序が立つこと |
| **E2** | 閉鎖系の創発 | 外部駆動なしで構造が**生成**すること+**ノックアウト対照**(機構を外すと消える) |
| **E3** | 頑健性を確認した創発 | E2 に加えて**多seed・粒子数変更・摂動**でも同じ現象が立つこと |

#### 標準試験(6試験)

E2/E3 を主張するサンプルは、下の試験を実測ハーネス(`tests/exp-*.mjs` → `tests/out/*.json`)で
通し、数値を説明文と `claims` に書き戻す。**通らなかった試験も数値ごと記録する**
(通らない試験の記録は、通った試験と同じだけ価値がある)。

| # | 試験 | 問い | 落ちるときの意味 |
|---|---|---|---|
| ① | **ノックアウト対照** | 機構を1つ外すと現象は消えるか | 現象は初期条件の側にあった |
| ② | **用量反応** | 駆動因を強めると単調に強まるか | 主張している駆動因が違う |
| ③ | **多seed** | 乱数の引きが変わっても立つか | 「それらしく見えた固定seed」だった |
| ④ | **粒子数スケーリング** | 特定の粒子数の離散模様ではないか | 分解能の産物だった |
| ⑤ | **摂動回復** | 壊してもまた立ち上がるか | 一回限りの配置で、自己維持していない |
| ⑥ | **時間窓** | 成立する時間帯はどこか(`validT` と整合するか) | 展示している時刻がたまたまだった |

⑤ の摂動は**実験操作であってアプリの機能ではない**。ハーネスが構造形成後の状態を直接
書き換える(速度ノイズは質量重みつき平均を差し引いて**系の全運動量を保存**させ、
「外から蹴った」ではなく「内部をかき混ぜた」摂動にする)。注入は保存則の帳簿を意図的に
破る操作なので、注入を含む run では |ΔL|/L_scale を判定に使わない。

**④ で分かった方法論の訂正(連結成分の個数は n で割っても示強にならない)**: 断片形成系では
**断片の大きさの分布**が示強量なので、最大断片の粒子数は総粒子数に比例しては伸びず、

同様に `成分数/n` は平均断片長の逆数である。したがって④「特定の粒子数の離散模様ではないか」の

記録するだけにした。スケーリングの設計自体は 第83便A の教訓(n が総質量と分離できない)を
