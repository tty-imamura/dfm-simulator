## 0. 公理の改訂と追加

### A13(相互性)— 原仮定者による改訂 ★最重要
> 空間の引きずりは、厳密には反作用を生じ、運動量を保存する。
> リンゴが地球に落ちるとき、地球もリンゴに引っ張られている。

**公理文**: すべての相互作用(重力・スピン斥力・フレーム引きずり・接触・スピン拡散)は
対ごとに作用反作用対称であり、系全体の線運動量と全角運動量
L_tot = Σ m_i(**r**_i×**v**_i) + Σ I_i s_i を厳密に保存する。
背景決定力 D₀ との運動量交換は、静止した無限慣性リザーバ(遠方宇宙)への移譲として
帳簿づけされる — リンゴに引かれた地球が、感知できないほど僅かに動くのと同じである。

これにより旧 THEORY_SYNTHESIS §7 の限界 **L2(保存則の破れ)は解消**され、
「保存則を厳密に満たす関係論的力学」として理論の格が一段上がる(新定理 T7)。
実装上の改訂は §1 の E5′/E6′/E10′。

### A11(光の伝播と同時性)— 原仮定者による改訂
> 光は「決定した空間」を進み、観測者によるパラドックスは発生しない。

**公理文**: 光は各点の局所決定フレーム **u**(**r**) に対して等方的に速さ c₀/n(**r**) で
伝播する。座標時間 t は宇宙で一意(絶対的同時性)であり、固有時間 τ の遅れ(E7)は
時計の**動的な**遅れであって、運動学的な相対性ではない。
したがって同時性の相対性に由来するパラドックス(双子・同時刻の不一致)は原理的に生じない。
DFM は「優先フレームを持つ理論」であることを明示する — 決定力場そのものが媒質である。
帰結: 光は媒質 **u** に運ばれる(フレネル随伴の完全版、E8′)。回転体の左右で
光の湾曲が非対称になる(新帰結 T8 — Gemini が独立に提案したブラックホール実験と一致)。

### A12(放射)— 設計者による補完(**原仮定者承認済み 2026-07-15**)
D1(§2)の導出根拠と、旧限界 L3(法線減衰 γ_n の散逸先が不明)の解消のため追加する。

**公理文**: 温度 T_i を持つ質点は光量子を放射する。スペクトルのピーク波長は
ウィーン型則 λ_peak = b_m / T_i に従い(b_m はモデル定数)、光度は
Λ_i = η_rad · T_i^p(既定 p=4、シュテファン=ボルツマン型)。
E9 の法線減衰 γ_n で失われる並進エネルギーは、衝突時の閃光として放射される。
これによりエネルギー収支が閉じる: 並進 → スピン(摩擦)or 放射(法線減衰)、スピン → 放射(冷却)。

## 2. D1: 温度と光の波長からスピン速度の方程式を導く

A12(ウィーン型則)と温度定義 T = I s²/k_B を連立する。

> **s_i(λ) = √( k_B b_m / (I_i λ_peak) ) = (1/R_i)·√( 2 k_B b_m / (m_i λ_peak) )**

表面(接線)スピン速度はさらに簡潔になる:

> **v_surf = s_i R_i = √( 2 k_B b_m / (m_i λ_peak) )** — 半径に依らず、質量と観測波長だけで決まる

**帰結**:
1. 青い(λ 小)天体ほど速く自転する: s ∝ λ^{−1/2}。
2. 同じ色の2天体では、重い方がゆっくり自転する: s ∝ 1/(R√m) ∝ m^{−1}(R=r_R√m のとき)。

4. 気体デモの平衡(E10′: s 均一)では、大粒子ほど T = Is² が高く赤外側から可視側へずれる —
   実装の色マップ改修(§0)と整合する検証項目になる。

シミュレータ単位系(k_B=1): λ = b_m/(I s²)、s = √(b_m/(I λ))。b_m は UI パラメータ化する。

## 3. D2: 楕円銀河・レンズ状銀河・渦巻銀河の形状方程式

### (G1) 回転則 — DFM の銀河基本式

u_φ(r) 場の中を周回する星に **向心加速度 k_F u_φ v_φ/r** を与える(導出: 経路に沿う

> v_φ²/r = g_eff(r) + k_F u_φ(r) v_φ/r、 g_eff = G ∂_r D − a_rep,rad

これを v_φ について解くと **v_φ(r) = ½[ k_F u_φ + √( k_F² u_φ² + 4 r g_eff ) ]**。

### (G2) フレーム場の自己無撞着方程式と平坦域の長さ
u_φ 自身は内側の星々の回転から作られる(不動点方程式):

> u_φ(r) = [ ∫ Σ(r′) w(|**r**−**r**′|) v_φ(r′) dA′ + Σ_c w_c ω_c r ] / W(r)

円盤質量 M_d、平均回転速度 V̄ に対し外縁では w 総和 ≈ M_d/r なので
u_φ(r) ≈ V̄ · M_d/(M_d + D₀ r)。したがって:

> **平坦域**: r ≪ r_flat では v_φ ≈ k_F V̄(平坦)。 **r_flat ≈ M_d / D₀**
> r ≫ r_flat では u_φ → 0 となり v_φ → √(GM_d/r)(ケプラー減衰に復帰)

平坦部の自己無撞着条件 v_φ ≈ k_F v_φ + (重力項) は **k_F = 1 が特異的に自己整合的**で
あることを示す(k_F < 1 では平坦レベルが内側平均より下がる)。
**モデル内予言**: 回転曲線は無限に平坦ではなく、半径 M_d/D₀ で折れる。D₀ を上げると
平坦域が縮む — シミュレータで直接検証可能。

### (G3) 形態分類 — 3つの無次元数

  エピサイクル振動数 κ_eff² = r dΩ_eff²/dr + 4Ω_eff²、Ω_eff = (v_φ − k_F u_φ)/r)

**分類則**(境界値 h_c, Q_c は数値校正、初期見積り h_c ≈ 0.3, Q_c ≈ 1.5):

## 4. D3: 土星の環を安定形成する方程式

### (R1) 軌道則と回転方向の選択
中心天体(質量 M、スピン S_c、半径 R_c、静止)まわりのリング粒子の円軌道は (G1) の特別な場合:

> v_φ(r) = ½[ k_F u_c(r) + √( k_F² u_c(r)² + 4GM/r ) ]、
> u_c(r) = [ w_c/W ]·ω_c(r)·r = [ M/(M + D₀r) ]·S_c (R_c/(R_c+r))^q · r

u_c > 0(順行)側は必要な |v − u| が小さく、逆行粒子は大きなフレーム逆風を受けて
衝突散逸(E9)が激しい。ゆえに **環は中心天体のスピンと同方向に淘汰される**
(実在の土星の環が自転と同方向である事実の、モデル内での説明)。

### (R2) DFM ロッシュ条件(引きずりせん断つき)
粒塊(質量 m、密度 ρ)が潮汐+フレームせん断で引き裂かれない条件。
引きずりせん断数を **𝒟(r) ≡ k_F · | r ∂_r( u_c/r ) | / Ω_K(r)**、Ω_K = √(GM/r³) と定義して:

> **ヒル半径(2D)**: r_H = r · √( m / (3M) ) · [ 1 + c_R 𝒟(r) ]^{−1/2}
> 粒塊サイズ δ < r_H なら生存(衛星化)、δ > r_H なら破砕(環に留まる)
> 等価な臨界密度形: ρ_crit(r) = ρ_Roche,Newton(r) · [ 1 + c_R 𝒟(r) ]

(c_R は O(1) の校正係数。3D 移植時は指数 1/2 → 1/3。)
**帰結**: フレームせん断は実効ロッシュ限界を**外へ押し広げる** — DFM の環は
ニュートン力学より広い半径帯で安定に存在できる。

### (R3) 熱平衡幅と安定窓
衝突加熱と放射冷却(A12)の釣り合いが速度分散 σ_eq を決める:

> μ_f · n(r) σ_coll ⟨Δv²⟩ · μ̄ / 2 = η_rad Σ_i T_i⁴ / N ⇒ σ_eq(r)
> 環の厚み(動径幅): w_ring = σ_eq / Ω_K

**環の安定窓**(3条件の同時成立):
1. 重力凝集しない: Q_ring = σ_eq Ω_K/(πGΣ_ring) > 1 ⇔ σ_eq > πGΣ_ring/Ω_K
2. 衛星化しない: ρ_ring < ρ_crit(r) (R2)
3. 粘性拡散が遅い: t_spread = (Δr)²·Ω_K/σ_eq² ≫ 観測時間

1〜3 を同時に満たす半径帯 [r_in, r_out] が「安定な環」。σ_eq は自己調整的
(σ が上がる→衝突減→加熱減→σ 低下)なので、窓の中では **環は熱的アトラクタ**である。

### 10.2 アナロジーの定理化 — T9(時間パラドックスの座標化)

### 10.4 観測者転換後の「よりシンプルな法則」— 単一ポテンシャル ψ の統一時空則

現行の基礎表示では時間(E7: K_t)と光(E8′: k_lens)が独立係数を持つ。観測者を物質共動

### 17.9.1 何が起きるか

中心に大質量・高スピンの天体を置いた合成系(BH+ローター+恒星リング等)を長く走らせると、
帳簿を含めた角運動量の恒等式

  |ΔL| = |L(t) + resL + radL − L(0)|,  relL = |ΔL| / L_scale

が QA 閾値 1e-3 を超える。単一天体スピン `s`・半径 `R`・時計係数 `Kt` のような**個別の物理量**では
境界を書けない(同じ S_bh でも走行長で振れる)。一次指標として使えるのは
**E6′ が搬送した角運動量の累計**である:

  Γ ≡ | Σ_substeps Σ_i (r_i × Δp_i^{E6′}) | / L_scale

🕶️darkrotor v6 の BHスピン掃引(24000步・3チェックポイント=15点)の全点で

  **relL ≤ 0.1 · Γ**

が成り立つ(実測比は 6e-4 〜 6e-2)。**Γ は上界を与えるだけで十分条件ではない** —

### 17.9.2 原因は E6′ の飽和クランプ**ではない**(第38便 38C §3.5 の訂正)

第38便 38C は原因候補として E6′ 輸送の「1サブステップの引きずり量 0.8 飽和」を挙げ、
「飽和が効くと作用反作用の対分配が厳密でなくなる」と推定していた。**これは誤りである。**

飽和は Δu をクランプした**後**に Δp_i を確定し、反作用パスはその確定済み Δp_i を
φ_ij = w_j(r_i)/W(r_i) で比例配分する。受け手 i について Σ_{j≠i} φ_ij + φ_bg ≡ 1 が
恒等的に成り立ち(W(r_i)=D₀+W_B+Σ_{j≠i}w_j と同じ式)、各ソースへの適用は
「軌道項 −(r_j×ρ)」+「残余トルクのスピン移譲 −((r_i−r_j)×ρ)」= −(r_i×ρ)、
固定粒子・背景持ち分はリザーバへ同量 −(r_i×ρ) を計上する。したがって

  反作用パスが取り去る L = −Σ_j φ_ij (r_i×Δp_i) − φ_bg (r_i×Δp_i) = −(r_i×Δp_i)

で、**クランプは Δp_i の大きさしか変えず、対分配の恒等式には一切効かない**。
実測でも φ 分配の閉じ残りは相対 1.8e-6 = float32 の機械イプシロン水準にとどまる。
さらに飽和の発動回数と破れの大きさは**逆相関**する(発動が最多の S_bh=0.12/1 で relL 最小、
発動が最少の S_bh=4/8 で relL 最大)。

### 17.9.3 真因

状態配列(`x, y, vx, vy, spin, m, R, …`)はすべて `Float32Array` で保持される。
E6′ 反作用パスは1サブステップに O(N²) 回の微小増分を書き込む:

  `spin[i] -= dsn`        (残余トルクの等角加速度移譲。dsn = n_ij/(I_i+I_j))
  `vx[j] -= rpx / m[j]`   (ソース j への反作用インパルス)

いずれも増分が `|値|·2⁻²⁴`(≈ 6e-8·|値|)を下回ると丸めで**そのまま消える**。
高スピン域では系が飛散して |v| が大きくなる一方、1 対あたりの反作用は φ_ij ∝ 1/N と小さいので
吸収率が跳ね上がる(実測: 反作用インパルスが**完全に**消える割合は S_bh=0.12 で 0.6%、
S_bh=4 で 88%、S_bh=8 で 94%)。段階別の監査では、破れ全体の **100%** がこの2行で説明できる
(24000步時点。`tests/out/exp-4-73.json`):

|---|---|---|---|---|
| 0.12 | −6.84 | −13.0 | +6.20 | **100.00%** |
| 1 | −2.86e+3 | −3.65e+3 | +7.87e+2 | **100.00%** |

| 8 | −5.68e+5 | −5.30e+5 | −3.87e+4 | **100.00%** |

他の段階の寄与は桁違いに小さい(S_bh=4・24000步で ①=+0.06、②の E6′ 以外=−2.4e+3、

### 18.1 出発点と展開

物質作用は §15.1 のまま(E7R の作用化):
  S_m = −mc²∫dt √(N² − A²|v−u(r,t)|²/c₀²)、 N=e^{−ψ}, A=e^{+ψ}, ψ=W_ext/K_t
第1段階(geoPN=1)は u=0 と置いた。第2段階は u(r,t) を残したまま弱場1PN

  L = ½m w² + mU − mU²/(2c²) + (3/2)mU w²/c² + m w⁴/(8c²)、 U = c²ψ = G·W_ext

これは標準の1PN試験粒子ラグランジアン(等方計量 β=γ=1)の **v→w 置換**に一致する。
オイラー=ラグランジュ方程式で ∂w/∂r = −∇u に注意すると(∇×u は 2D のスカラー渦度):

  **dv/dt = ∂u/∂t + (u·∇)u + (∇×u) ẑ×w + ∇U + a₁ₚₙ(w)**
  a₁ₚₙ(w) = (λ/c²)[((α−½)w² − (1+2α)U)∇U − (1+2α)(∇U·w)w]

部分相対性(kFrame)の一般化は w = v − k_F·u・輸送3項に k_F を乗じる
(k_F=1 が完全相対空間・k_F=0 で第1段階へ厳密退化)。

### 18.2 3つの輸送項の物理

1. **∂u/∂t + (u·∇)u**(フレームの自己加速): 物質はフレームごと運ばれる —
   **legacy E6′ の Δv=k_F·Δu 輸送はこの項の離散版**(現象論が作用から再導出された)。
2. **(∇×u) ẑ×w**(渦度コリオリ): 回る u 場が特異速度 w を偏向する —
   **フレームドラッグの正体**。剛体回転 u=Ω ẑ×r では ∇×u=2Ω となり、
   コリオリ係数 2Ω が「仮定なしで」出る(§18.3 P4a-3 で機械確認)。
3. **a₁ₚₙ(w)**: 現行 E12 式の v→w 置換。u=0 で §15.1 と厳密同一。

### 18.4 帳簿設計(裁定=反作用返し)

- **輸送3項**: 粒子 i が受けた Δp_i = m_i·(輸送項)·dt の反作用を、u の決定力持ち分
  φ_ij = w_j/W(r_i) で源 j へ返す — **既存 E6′ ③パス(対分配+残余トルク+背景リザーバ)を
  そのまま流用**(40A の倍精度アキュムレータ込み)。背景 D₀+W_B の持ち分は従来どおり
  リザーバ帳簿へ。
- **a₁ₚₙ(w)**: ∇U = Σ_j ∇U_j と分解できるため、各項の ∇U_j 因子に対して対ごとの
  反作用(−m_i a_ij を j へ)を返せる — 運動量は対で厳密に閉じる。スカラー因子(U・w²)は
  対分配に影響しない。第1段階(pinned 源・開放系)からの拡張点はここ(自由源の連星系で
  P・L モニタが閉じることが実装時の V ゲート)。

### 18.6 実装記録(2026-08-03 第69便 P4b — beta v1.36-b6)

§18.5 の計画どおり beta に実装した。離散化の要点と V ゲート実測:

- **輸送3項の離散化**: ∂u/∂t+(u·∇)u = [粒子追跡の u 差分 Δu_path/dt] − ((v−u)·∇)u と分解する。
  Δu_path は legacy E6′ と同一の帳面(uPx/uPy — 前サブステップの粒子位置での u)で測り、
  勾配補正と渦度コリオリ (∇×u)ẑ×w は**解析勾配**から作る:
    J_ab = ∂u_a/∂x_b = (∂P_a/∂x_b − u_a·∂W/∂x_b)/W、 ∇×u = J_yx − J_xy
  (u=P/W。∂w_j/∂r = −m_j(r−r_j)·invW³ は E1′ Plummer 型の厳密微分、スピン項は
  ∂ω/∂d = −q·ω/(R+d) — コア差動分は −q·ω_c/(Rc+d)。箱 u_B の勾配は定数行列 [[H,−Ω],[Ω,H]])。
  勾配集積は geoPN=2∧kFrame>0 のときだけ確保・実行(既定経路ゼロコスト)。
  Δv には E6′ と同じ 1 サブステップ上限 0.8 を課し、Δp は既存③パスへ流す。
- **1PN の w 置換**: w=v−kF·u の u は直前サブステップの追跡値(uPx)。geoPN=1・kFrame=0・
  初回(hasU=0)のいずれでも w=v が**厳密に**成り立つ(bit 等価の要)。対反作用
  −(m_i/m_j)a_ij は自由源のみへ返し(pinned 源は E4 と同じ外部拘束=第1段階と同じ開放系)、
  残余トルクは③と同じ等角加速度でスピンへ移譲する。
- **V ゲート実測**(tests/exp-p4b.mjs・QA geo2.* 3本で機械固定):
  ①bit等価: ☿型(pinned 源)1500步で全状態厳密一致(不一致 0)
  ③共動連星: 等質量自由源対+トレーサ(D0=0)を V=3 ブースト — 分離窓平均の相対差 **0.75%**
  ⑤保存則: 自由連星+惑星2(D0=0・3000步)で |ΔΣP|/Σm|v|=1.3e-6・|ΔΣL|/|L₀|=6.6e-6 —
  geoPN=1 の開放 1PN(1.7e-4)を対反作用で**約26倍**閉じる
  ④🎡リトマス(初実測・裁定材料): 外縁増強 kF1/kF0 = **1.0803**(legacy 1.2646 は同走で
  厳密再現)— 作用由来の渦度コリオリ+輸送からは legacy 現象論の約 1/3 のドラッグが出る。
  スピン源ドラッグの残り 2/3 は legacy Δv=kF·Δu の「勾配補正なし」離散化に固有の成分で、
  どちらを正とするかは次の裁定事項(§18.2 の理論的正当性 vs 較正済み現象論)。
- 周辺観察(P4b 起因ではない): D0=0 かつ極端質量比(1:10⁴)では③反作用の φ 対分配が軽い側へ

  legacy(geoPN=0)でも同一に実測 — E6′③ の既存特性(D0>0 の実用構成では φ が薄まり無害)。
