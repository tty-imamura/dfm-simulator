# 研究用 RC の条件(第282便e・原仮定者の裁定(第72報)AA16)

本書は、DFM シミュレータの開発線(beta)を**研究用のリリース候補(RC)**として区切るときに満たすべき条件を置く。
**本書を置いた第282便では RC を切らない**(原仮定者の裁定(第72報)AA16 —— 条件文だけを docs/dev に置く)。
条件は**判定を甘くするためのものではない**。満たしたことは「研究に使える形で開示できる」ことだけを意味し、
観測との一致や理論の成立を意味しない。

## 開示の分離(全項目に共通)

- **kF0 の観測合・DFM の概略整合・アナロジーの形状達成は別々に開示する。** 3 つを 1 つの合率や 1 つの印にまとめない。
  - kF0 の観測合: 現実較正 kF0 版(f=1・kFrame=0・geoPN=1)で、宣言した観測量が合/否/数値未解決/写像未解決のどれか。
  - DFM の概略整合: 現実参照 DFM 版(f=1・kFrame=1・geoPN=1)で、系統ごとに**事前に宣言した許容幅**に対して概略整合/調整中/適用外と残差。
  - アナロジーの形状達成: アナロジー系列(f=1・geoPN=3・中心 DFM ブラックホール)で、形状の達成/未達・収支・適用窓。
  - 比較系列(同じ入力で geoPN=2/3)は主系列の合を代用しない。
- **観測 3σ 合は条件にしない。** 合の本数は RC の条件ではなく、そのときの状態として開示する(否・数値未解決・写像未解決も同じ表に並べる)。
- 旧契約の集計(4 値 0/2/2/33 など)は**旧契約の履歴**として残し、新しい集計には母集団・法則版・対象観測量を明記する。
  DFM 版を母集団から外して合率が上がったように見せない。

## 条件

### ① 法則・速度・参照系・単位の契約

- 内蔵の各本が**法則の版**(geoPN・`spaceMesh.lawVersion`・`pn`・`pnVelocity` 等)・**速度の意味**(`velocityMeaning` —— 座標速度 ẋ か慣性速度 v か)・
  **参照系**(背景の有無・comoving・`mutual`)・**単位**(スケール指数・G・c₀)を宣言し、受理(`validatePreset`)で機械照合される。
- 宣言が欠けた本、受理で既定値へ寄せた本(スナップ・移行)は、その事実を概要とカードに出す。契約の穴(例: geoPN=1 の自由連星の反作用の扱い)が
  見つかっている系列は、その系列の結果を「契約未確定」として開示する。

### ② NaN・縮退・閉包失敗の可視化

- NaN・クランプ・縮退(近接・合体・特異な配置)・閉包の失敗(判定器の写像未解決、再生成範囲の `complete:false` 等)を**隠さず**、
  概要・観測カード・状態一覧・QA のどこかに数で出す。
- 失敗した走行を途中までの値で判定へ流さない(停止規則の資源上限は unmeasured として扱う)。

### ③ 閉じた系の E/P/L と開いた系の交換帳簿

- 閉じた系(外部の場も背景も無い)では、エネルギー E・運動量 P・角運動量 L の保存誤差を刻みごとに開示する。
- 開いた系(背景・外部源・`mutual:0`・固定中心)では、保存量の代わりに**交換の帳簿**(系が受け取った量と渡した量)を宣言して収支を閉じる。
  相対論的な全運動量は Σmv ではないので、何を保存量として数えるかを帳簿の側で定義する。

### ④ 主要診断の刻み・軟化・窓の収束

- 主要診断(近点移動・周期・自転の相対位相など)は、刻み dt(dt・dt/2・必要なら dt/4)・軟化 ε・時間窓(周回数)を変えた系列で差を記録する。
- 収束を示せない量は「数値未解決」として開示する(刻みを細かくした先の見通しを判定の代わりにしない)。

### ⑤ 概要・カード・保存の一致

- 各本の概要・観測カード・状態一覧(`SAMPLE_STATUS`)・保存 JSON(`presetSig`)が、同じ数・同じ判定語・同じ法則版を持つ。
- 生成物の一致は QA(`samplestatus --check`・`assessed --check`・来歴の刻印 `lint.provenanceMeta`・再生成範囲 `lint.regenScope`)で照合する。
  正本 JSON の来歴(対象 html の hash か領域 hash・入力・器)が今のファイルと一致しない正本は、RC の開示に使わない。

### ⑥ beta と root の必要 QA

- beta: フル QA が ALL PASS・`bitsame`/`sigsame` を基点と比べて差分 ID を記録・perf の門。
- root: RC へ昇格させる時点で root のフル QA と perf を回す(beta 専用のブロックは root で SKIP になることを確認する)。
- CI(Node 24)を最終の裁定とし、手元(Node 22)との最下位ビットの差は正本の再導出比較を相対 1e-12 で行う。

## 本書の位置づけ

- 条件を満たしたことを、物理の主張の根拠にしない(開示の形が整ったことだけを意味する)。
- 観測との比較の結論(合の本数・否の本数)は、本書ではなく各便の記録と状態一覧(`docs/SAMPLE_STATUS_v1.45.md`)に置く。
