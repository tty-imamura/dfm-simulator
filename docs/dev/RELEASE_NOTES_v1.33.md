# v1.33.0 リリースノート(ドラフト・GitHub Release 本文用)

第40便(2026-07-28)作成。第35〜39便(2026-07-26〜28)の beta 先行実装を、機械QA・
性能ゲートの実測確認のうえルートへ昇格した版。以下は GitHub Release 本文の草案(ja)。
公開判断・タグ付けは原仮定者が行う(「リリース前の残チェックリスト」参照)。

## 要点

- **温度を内部状態変数化(A9′・tint)+第一法則帳簿**: プリセット単位のオプトイン
  `thermal:"tint"` で粒子ごとに内部温度 T_int を保有。衝突・摩擦の散逸は T_int になり、
  熱伝導(κs)は熱だけを運びスピンを動かさない(角運動量が自明に厳密保存)。E5′ の対
  ポテンシャル U_rep を帳簿化し、融解潜熱が力学の帰結として自然発生(吸熱の約73%が
  U_rep へ)。非移行プリセットは1ビットも変わらない(QA `tint.zero-cost`)。
- **伝熱する箱(thermalWalls)**: pinned 全廃・面ごとの heat/rad/断熱境界+帳簿
  wallEin/Eout/wall吸収KE/放射。♨️は床加熱・天井/右壁放熱・左壁断熱+一様重力だけで
  24000步の循環を持続(定常熱流。帳簿の閉性 1.07e-4)。
- **🕶️darkrotor v6(中心BH+対向2ローター)**: ローター10体構成から対向2体へ再設計し、
  24000步の恒星保持率 87.9%(旧構成 38.7±13.0%)へ改善。誠実性の記述として、2体配置
  自体が m=2 四重極を持つため対照にも配置由来の腕が残ることを明記し、スピン起因分は
  用量反応で分離。
- **🌪️spinup(収縮とスピン加速)新設**: 完全閉鎖系の自己重力雲(kRep=0)がコアへ収縮し
  スピン加速する過程を機械検証(コア半径 3.02倍収縮・ω_core ×8.46・保存則帳簿
  [0,0,0])。教材的トイモデルであることを明記。
- **「掻出」→「減光」改称+λ0スライダー・可視外記号色**: UI表示名を直感的な用語へ変更
  (JSON キー・API は互換のため不変)。光線の基準波長 λ0 をスライダー化し、可視外は
  γ線/X線/紫外/赤外の記号色で表示。
- **平均温度グラフの色付け+温度バッジ・validT**: 温度グラフのバー・折れ線を粒子と
  同じ色写像で表示。「温度=T_int」バッジと有効時間窓(validT)の HUD 評価窓外マーカーを
  追加。
- **性能最適化(bit同一)**: I=½mR² の事前計算・E10′ の遠方対足切り・反作用ループの
  巻き上げ・tint 系配列の単型化により、暫定 perf ALLOW(darkrotor/convection/
  saturnLayered)を全て撤去。昇格後は root==beta のため perf 8ゲート
  (galaxy/darkrotor/merger/convection/counterring/saturnLayered/echo/freebox)が
  全て比≈1.0 で PASS。
- **既知制約(重要)**: 高スピン合成系(実装上は S_bh≥2 級・一次スクリーニングは
  relL=|ΔL|/L_scale が 1e-3 を超える走行)では、保存量・角運動量収支は単精度(Float32)
  の丸め誤差に支配されており、モデルの物理的帰結として主張しない
  (`docs/DERIVATIONS.md` §17.9)。既定プリセットはすべてこの領域の外にある。QA ガード
  `conservation.float32-range` / `conservation.float32-canary` がこの境界を機械固定。

本シミュレータは「仮定の物理法則」(決定力場モデル: DFM)の帰結を観察する思考実験・
教育用ツールであり、現実の物理学の代替理論を主張しない(README「本プロジェクトの
位置づけと限界」)。
