## 2. 論文の主張構造(3部)

### 第1部 — 箱という近似(理論)
1. 箱宇宙の意味論6項目(§12)— D₀・一様重力も概念上は箱のパラメータ
2. T10: 並進は内部から検知不能(厳密)/回転・膨張は利得 g(r)(2D一様リング中心で 1/2 —
   解析導出 ⟨n̂(n̂·r)⟩=r/2 と実測 V23a/V24a)
3. 完全な箱 = UniverseBox(連続背景)と質点壁の役割分担

### 第2部 — 膨張の3層(運動学・意味論・動力学)
1. 運動学: 規定 a(t)・完全共動 χ=r/a(V24b)・φ_B 則(束縛系 d∝a^{2φ_B} — V25)
2. 意味論: 波長保持則 1+z=a_obs/a_emit(4-63)と A/B/C 同時観測(🔦・QA box.photon-abc)。
   DES 時間伸長・CMB T(z) との「式の水準の一致」(§13.1)
3. 動力学: **自由な箱(第35便・T12)** — 膨張則を「解く」: 圧力駆動の加速膨張
   (E5′ が 1/d 減衰で重力より緩いため)vs 自己重力の再収縮。フリードマン類似の機構デモ
4. (補)時間の矢: leapfrog+Loschmidt echo(T11)— 「巻き戻る宇宙」の機械実証

### 第3部 — プローブ依存の膨張測定(本論文の新規性の中心)
1. **ハッブル反摩擦と比率基準の整合**(§12-5 v1.5・§13.2): w は絶対時間基準で保存するが、
   局所光速が決定力希釈で上がるため比 w/c_loc は低下 — 減衰方向は GR と整合へ
2. **プローブ依存 H(4-66 存置裁定の展開)**: 幾何プローブ(χ・壁距離)の H_geo に対し、
   速度減衰プローブを FLRW 型(w/c∝1/a)と仮定して読むと
   **H_w = 2·(D/Kt)·a^{−dPower}·H_geo**(E8R 指数形 R(a)=e^{−2(D/Kt)(1−a^{−dPower})} の
   対数微分)。プローブにより H の推定値が食い違う。
3. **「D/Kt ≈ 0.92」とハッブルテンションの類似(原仮定者指摘 2026-07-27)**:
   実宇宙のテンション比 H_CMB/H_local = 67.4/73.0 ≈ 0.923。DFM 箱宇宙では
   D/Kt≈0.92 のとき a=2 で H_w/H_geo = 0.92 となり、**「測り方(プローブ)が違うと
   H が食い違う」構造がテンションと同型**。主張水準: 数値一致の主張ではなく
   「プローブ依存 H という機構がテンション類似の現象を生む」構造の提示に留める。
   → **V29(新設・論文前提)**: 同一箱で光基準 H・速度基準 H・幾何基準 H を測り、
   H_w/H_geo = 2(D/Kt)a^{−dPower} の解析式と機械一致させる(第36便以降のQA固定が前提)
4. 早期/晩期の構造対応: ρ(a)=2(D/Kt)/a^{dPower} は a とともに低下 — 「観測時期・手段で
   H が変わる」というテンションの構造的骨格を最小モデルで示す

### 第4部(または第3部内の節)— 光学的に暗い重力体(原仮定者指定の言及)
1. **高速スピンコアの光の掃き出し(外来光線)**: BH コアのスピンが高速になると外来光線を
   系外へ掃き出す(強場回転フレーム — T10候補・DERIVATIONS §17 登録済み=4-48)。
   第36便実測: 非脱出の立ち上がりは s=0.5〜1.0 の用量反応・**物理対応ロック(K_t=c²/G)で
   完全消失**(強場トイ域の現象 — 誠実性の柱として本文に明記)。
2. **自光の掻出(lightSweep)は別機構**(第36便 E2 で直交性を機械実証 — 同時刻の光線終端は
   lightSweep に不感)。第36便 C2 の auto 算出則 lS_eff=min(1,|s|R/c_surf) により
   トイ設定(固定1)を式に置換可能(🕶️BH で機構値 0.56 vs トイ値 1 の差も本文で開示)。
3. **「ダークマターの要件」への言及**: この天体はモデル内で
   (i) 質量として W に寄与し重力する (ii) 光学的に暗い(自光は掻出②・外来光線は掃き出し③・
   ただし②③は独立機構 — DERIVATIONS §17 の分解表を引用)
   (iii) 銀河スケールの回転曲線増強に寄与(T4+ダークローター) — すなわち
   **「観測的に暗いが重力する」という DM の現象論的要件をモデル内で満たす**。
   主張水準(厳守): 実宇宙 DM の説明の主張ではない(Negative Claims 1/2/4)。
   第19便レビューの9反証条件のうち4成立+1部分成立(現行公理で「BH=DM」は不採択)を
   明記した上で、**要件を満たす合成機構(質量+並進引きずり+整列スピン+光掻出)**として
   提示。定量根拠(第36便実測): 4-48 分解表(DERIVATIONS §17)・4-49 半径依存
   プロファイル(内側ほど増強比大 1.58→1.15 — 8seed 統計で確定)・4-47 u_req 逆問題
   (前方予測は残差≈2%で妥当・設計は u_φ 飽和が律速で外縁未達 — **限界の定量化として
   誠実に記載**)。
