# 観測データのアプリデータ化 — 手順書(HANDOFF)

- 版: v1.0(2026-07-25・第26便)
- 目的: **アプリに該当データが無いが、現実の観測データが取得可能な場合**に、その観測値を
  DFM Simulator のプリセット(physics / bodies / zonal 等)へ落とし込む手順を確立する。
- 適用実績(本手順の抽象化元):
  - 🛰️ `saturnZonalD68` — Cassini 重力解 J2〜J12(帯状重力調和係数)→ `zonal.J` + `zonal.calib`
  - 🌍/🌕 `earthMoon` / `earthMoonFree` — PREM コア質量比 32.5%・LLR 月コア比 1.68%・
    実自転比 27.4× → `coreMR` / `spin`
  - 🛰️ `grcal` — GPS 時計 +38.5μs/日・光偏向 1.7512″・シャピロ ≈281μs → `Kt=c²/G` 較正
  - 🕶️ `darkrotor` — 高速回転ブラックホールの類比 → `coreMR`/`coreSR`/`lightSweep`(参考サンプル型)

## 1. 手順(7ステップ)

1. **観測量の選定と一次ソースの記録**
   モデルに写像できる量(質量比・半径比・角速度比・調和係数・時計率差など)を選ぶ。
   一次ソース(ミッション名・カタログ・論文)と取得日をプリセットのコメントに残す。
2. **単位系の写像(3基準)**
   sim 単位は長さ・質量・時間の3基準で決める(例: 🌍は 月軌道半径=180 sim、地球質量=1000 sim、
   月公転周期=2π/ω sim)。**無次元比(質量比・半径比・J係数・自転比)はそのまま持ち込める** —
   これが最も頑健な経路であり、優先する。
3. **物理対応条件の判定**
   時計・光を定量で写す場合は `Kt = cLight²/G`(物理対応ロック)を満たす値を選ぶ。
   満たさない場合は「画面用の誇張アナログ」であり、説明文にその旨を明記する(☿の例)。
4. **エンジン制約の確認**
   Float32(比較は許容差)・softening ε(解析式は Plummer 込みで検算)・dt=0.016×substeps・
   E6′ 安定域(u·ω ≪ g — 実自転比が安定域を超える場合は 🌍型の「圧縮した展示系」と
   🌕型の「kFrame=0 の物理比」の2系統に分ける)・D0=0 禁止。
5. **較正係数の許容(fitting ではなく較正)**
   離散化・軟化の系統残差は、解析式との比 1 本の係数(例: `zonal.calib=1.000302283`)で吸収し、
   機械検証で固定する。観測へ合わせるための自由パラメータ追加(fitting)は Negative claims の
   規律に反するため行わない(BOX_UNIVERSE 裁定 #11〜#13)。
6. **QA ゲート化**
   ①解析式との一致(例: zonal.analytic-d68)②実機挙動のしきい値(例: behavior.earthMoon の
   半径ドリフト・同期誤差)③乱数を使う場合は明示 seed。しきい値は較正実測×2倍マージンが定石。
7. **説明文への防御線**
   「現実較正」か「無次元スケール模型」か「誇張アナログ」かを説明文で区別する
   (README の Negative claims と同じ主張水準を維持)。

## 2. AI生成の活用(第26便のベースサンプル選択との連携)

観測値を JSON に整形する作業は、AIタブの**ベースサンプル選択**で近い参考サンプルを土台に
指示するのが速い(例: 🕶️をベースに「コア質量比を◯◯の観測値 X% に、半径を Y に」)。
バリデータが値域クランプ・構造検査を行うため、生成後は
①クランプ警告の有無 ②挙動の目視 ③必要なら手順1〜7で正式サンプル化、の順で確認する。

## 3. 観測量 → アプリキー対応表

| 観測量の型 | 一次ソース例 | アプリ側キー | 注意 |
|---|---|---|---|
| 質量比(コア/全体・伴星/主星) | PREM・LLR・天体暦 | `coreMR`、bodies の `m` 比 | 無次元 — そのまま |
| 半径・扁平 | 掩蔽・測地 | `radius`、`coreRR`、扁平率 f(表示) | f=5s²R³/(4Gm) は表示量 |
| 自転/公転角速度比 | IERS・暦 | `spin` / 軌道初速 | E6′ 安定域を確認(手順4) |
| 帯状重力調和係数 J2n | Cassini 等の重力解 | `zonal:{refR, J:{...}, calib}` | 奇数次は非対応(無視) |
| 時計率・光偏向 | GPS・VLBI | `Kt`(=c²/G)、`cLight` | 物理対応ロックで導入 |
| 温度・光度の見掛け | 測光 | `obsT`、`lightSweep`、`coreOT` | 表示のみ(力学不変) |

## 4. 受け入れ条件チェックリスト

- [ ] 一次ソースと取得日がコメントに記録されている
- [ ] 無次元比はそのまま・次元量は3基準の写像式が明記されている
- [ ] 物理対応条件(Kt=c²/G)の成立/不成立が説明文で区別されている
- [ ] 較正係数は解析式との比1本のみ(fitting なし)で、機械検証に固定されている
- [ ] 専用 QA(解析一致 or 挙動しきい値)があり、乱数は明示 seed
- [ ] フル QA が root/beta とも ALL PASS
