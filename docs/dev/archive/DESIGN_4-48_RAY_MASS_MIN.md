# 台帳4-48 残課題の検討 — RAY_MASS_MIN を光速と G から導出する

- 作成: 2026-07-29 第44便(検討=Fable 5)。原仮定者指示「RAY_MASS_MIN を光速と G から
  計算する事を検討する」。
- 現状: `RAY_MASS_MIN = 40`(固定・「光線を曲げる最小質量 — 性能のための近似」)。
  `PN_MASS_MIN = 40` も同方針。人工性: m=39 は全く曲げず m=40 は完全に曲げる階段で、
  物理的意味を持たない(4-48 の残課題)。

## 1. 物理化の提案 — しきい値を「質量」から「偏向角」へ

モデルの光線偏向は n=e^{2ψ}(ψ=W/Kt)に従い、弱場で GR 類似
**α ≈ 4ψ(b) = 4·m/(Kt·b)**(b=最接近距離)。天体 i が光線に与えうる最大偏向は
b ≳ max(R_i, ε) で

```
α_max(i) = 4·m_i / (Kt · max(R_i, ε))
```

そこで「**偏向が分解能 α_min 未満の天体は光線源から除外**」という物理基準に置き換える:

```
天体 i が光線を曲げる ⇔ m_i ≥ (α_min/4) · Kt · max(R_i, ε)
```

- **光速と G との接続**: 物理対応ロック Kt = c²/G のとき、しきい値は
  **m_min = (α_min/4)·(c²/G)·max(R,ε)** — まさに「光速と G から計算」される
  (GR の偏向式 α=4Gm/(bc²) の逆読み)。ロック無しの sim でもその sim の Kt で同式が成立。
- 人工定数は「質量40」から「**分解能 α_min**」1つへ置換される。α_min は表示上の意味
  (これ未満の曲がりは1pxに満たない等)を持てる点で誠実。

## 2. 現行値との整合(較正の実測)

現行 40 が相当する α_min は Kt 依存: ε=4 のとき α_min = 40·4/(Kt·4) = 40/Kt rad。
- Kt=300(箱系): α_min ≈ 0.133 rad(7.6°)— かなり粗い
- Kt=50(galaxy): α_min ≈ 0.8 rad — 実質「主天体のみ」
- Kt=3600(物理ロック系): α_min ≈ 0.011 rad

つまり**現行の固定40は、Kt が大きい(=物理ロックに近い)プリセットほど厳しい基準に
相当している**。物理化すると α_min 一定の下で Kt 小のプリセットの heavy 集合が拡大し、
光線コスト(トレース・キャッシュキー)が増えうる — ここが唯一のトレードオフ。

## 3. 実装案と検証計画(次便 — 裁定後)

1. `rayHeavy(i) = m[i] >= RAY_ALPHA_MIN/4 * Kt * max(R[i], softening)` へ置換
   (RAY_MASS_MIN 定数は撤去。PN_MASS_MIN も同式で置換 — E12 の 1PN 補正も偏向角と
   同スケールのため同基準が自然)。
2. α_min 既定の較正: 全39プリセットで新旧 heavy 集合を機械比較し、
   (a) 表示が変わるプリセット(新たに曲げ始める天体)を列挙
   (b) perf 8ゲートで光線系(lensing/blens 等)の退行なし
   を満たす最大の α_min を採用(候補 0.01〜0.05 rad を掃引)。
3. QA: `ray.alpha-threshold`(heavy 集合が式どおりであること+α_min 直上/直下の
   カナリア対)。基準スクリーンショット: heavy 集合が変わるプリセットのみ意図的更新。
4. 光線キャッシュキー(v1.22)は heavy 集合に依存 — 集合算定の変更に追随させる。

## 4. 裁定伺い

- **α_min の意味づけ**: (a) 固定の物理値(例 0.01 rad)/(b) 表示分解能連動
  (1px/光路長 — 画面依存になるため bit 安定性は劣る)。**推奨 (a)**(決定論・QA 安定)。
- 適用範囲: RAY_MASS_MIN のみか、PN_MASS_MIN も同時か。**推奨: 同時**(同方針の近似)。
- 実装波の割当: 実測較正を伴うため **Opus または統括直轄**(追補8 の規律)。
