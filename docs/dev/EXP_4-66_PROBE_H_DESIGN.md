## 1. 比較する2つの仮説(モデル内の関数形の選択)

| | 現行=E8R 指数形 | 対案=厳密反比例(4-66) |
|---|---|---|
| 光速則 | c_loc = c0·e^{−2ψ}(ψ=W/Kt) | c_loc ∝ 1/W |
| 膨張下の R=w/c_loc(W_B=D·a^{−dP}) | R(a)=e^{−2(D/Kt)(1−a^{−dP})} | R(a) ∝ a^{−dP}(dP=1 で厳密に 1/a) |
| FLRW 読みの H_w | H_w/H_geo = 2(D/Kt)·dP·a^{−dP} | **H_w/H_geo ≡ dP(=1)** |
| プローブ依存H | **あり**(a と D/Kt に依存) | **なし**(比が恒等値 — 全プローブ一致) |

**判別の核心**: 厳密反比例化を採ると、速度減衰プローブは幾何プローブと恒等一致し
(w∝1/a は FLRW の運動学そのもの)、**プローブ依存H — ハッブルテンション類似 — が消える**。
指数形は「近距離では GR 的減衰方向と整合(V28)しつつ、係数が a に依存してプローブ間の
食い違いを生む」— テンション類似の物語はこの関数形の帰結である。

## 2. 実験手順(V29 拡張 — 実装仕様)

1. **測定系列**: V29 の構成(規定 exp 膨張・単独自由粒子・friction:"dfm")をそのまま使い、
   3窓(a: 1→1.5→2→3)で H_w/H_geo を実測(V29 で稼働中)。
2. **D/Kt スキャンを追加**: D/Kt ∈ {0.3, 0.92, 1.5} の3点(0.92 は論文2の較正点)。
   指数形の予測: 比曲線 2(D/Kt)/a が D/Kt に比例してスケール。
3. **反比例対照**: 同一の w 実測値に対し c_loc∝1/W_B(規格化 c_loc(a=1)=c0·e^{−2D/Kt})で
   R を再計算した系列を並置 — 予測: H_w/H_geo=1(a・D/Kt に不依存)。
   ※コード変更なしで判別可能(対照は後処理 — E8R 本体の改変はしない)。
4. **判定基準**:
   - 指数形系列: |比実測/解析 − 1| < 1e-2(V29 と同一)かつ D/Kt 間で曲線が分離
     (隣接 D/Kt の比の差 > 10σ 相当 — 実測ノイズは V29 実績で 1e-3 台なので余裕2桁)
   - 反比例対照系列: |比 − 1| < 1e-2(恒等値の機械確認)
   - **分離の実証**: a=2 における指数形(=D/Kt)と反比例(=1)の差が判定精度の 10 倍以上
     (D/Kt=0.92 でも差 0.08 ≫ 1e-2 — 判別可能)
5. **出力**: tests/out/exp-4-66-results.json(a×D/Kt×2形の比のグリッド)— 論文2 fig6 の
   元データを兼ねる。実装先は tests/exp-4-66.mjs(exp-4-67/4-68c と同じ独立スクリプト方式・
   QA とは分離。V29 は現行のまま回帰ゲートとして残す)。

## 3. 裁定材料(4-66 本体の要否への含意)

- **存置(指数形)を推奨**: 反比例化は「プローブ依存H」という論文2の新規性の中心を消す。
  一方で指数形は V28 が示すとおり近距離減衰方向で GR と整合しており、「関数形の違いが
  観測(プローブ)の食い違いとして現れる」ことを教育的に示せる。
- 反比例形は**モデル内対照**として本実験・論文2 fig6 に常置し、「どちらを公理に選ぶかで
  何が変わるか」を明示する(Negative claims 3/6 の規律下で)。
- 4-66 台帳の扱い: 「存置+比較実験設計消化(第43便)」→ 実装(exp-4-66.mjs)は次便以降の
  量産波(設計確定済みのため Sonnet 可・QA_FAST 範囲)。
