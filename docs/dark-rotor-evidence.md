# ダークローターの根拠表(第286便c —— 原仮定者の裁定(第76報)④)

本書は **DFM のアナロジー天体「ダークローター」(DR)** の着想と、それに結び付けて挙げられた 4 件の観測記録を、**一次資料で言えること・言えないこと**に分けて並べる根拠表である。QA `docs.darkRotorEvidence` が節・4 件・出典・禁止語 0 を機械で検査する。数値の転記は下の出典の本文・要旨に印字されたものだけで、**判定の門には 1 行も接続していない**(`paper/data/transient-observations.csv` の行も `gate=not-connected`)。

## 1. 着想と定義

- **着想(DFM の計算結果)**: 天体(ブラックホール相当の中心)の自転が速すぎると、DFM の光の法則では光が回り込み、外から天体が見えなくなる —— という DFM の計算結果から着想したアナロジー天体である。
- **標準理論での位置づけ**: カー・ブラックホールの限界を超えて回転する天体。**超 Kerr は無次元の自転パラメータ χ = cJ/(GM²) で定義する**(角速度 ω では定義しない —— ω は半径や座標系で変わる)。標準の一般相対論では |χ| ≤ 1 のとき地平面があり、|χ| > 1 の解には地平面が無い(裸の特異点)。
- **宇宙検閲官仮説は仮説である**(定理ではない)。弱い宇宙検閲官仮説(Penrose 1969)は、一般的な重力崩壊で裸の特異点が外から見えることはないと**予想**する。これに従えば超 Kerr 天体は現実には作られないと考えられているが、証明はない。
- **DFM の天体に対応づける条件**: DR をこの定義に対応づけるには、**質量 M・角運動量 J・半径 R・光の法則**(どの経路の光が回り込むか)と、「地平面」の語を DFM で何と定義するか(光が外へ出ない境界を法則のどの量で決めるか)を**宣言してから**比べる。宣言の形式は決断事項候補として残す(本便では決めない)。

## 3. MOA を恒星質量へ置き換える場合の標準レンズ式と必要条件

点レンズの標準式(Gould 2000 の記法): **t_E = θ_E / μ_rel**・**θ_E² = κ M π_rel**・κ = 4G/(c² au) ≈ **8.144 mas/M☉**(π_rel = au(1/D_L − 1/D_S))。

- MOA-9y-5919 の θ_E = 0.90 μas を保ったまま M = 1 M☉ と置くには、π_rel = θ_E²/(κM) ≈ (0.90×10⁻³ mas)² / 8.144 mas ≈ **9.9×10⁻⁸ mas** が要る(本便の換算)。D_S ≈ 8 kpc なら D_S − D_L は**約 10³ au 程度**(レンズが光源のすぐ手前)になる。
- μ_rel = θ_E / t_E ≈ 0.90 μas / 0.057 日 ≈ **5.8 mas/年**は質量に依らない(典型的なバルジの値の範囲)。
- したがって恒星質量の解釈は「θ_E を保つにはレンズと光源の距離差が極端に小さい」ことを**必要条件**とする。これは**確率 0 を意味せず、反証でもない**(事前分布の中の小さい領域というだけ)。本便は確率を計算していない。

## 4. 蓄光→放出の帳簿(🐮 lfbotTrap との対応 —— 実装は本便ではしない)

第76報の仮説「DFM の減光で蓄積した光が天体の崩壊で一気に放出した」は、**貯蔵エネルギー E_res の帳簿**として書ける:

- **Ė_res = f_trap L_src − E_res / t_esc − L_loss**
- **L_out = (1 − f_trap) L_src + E_res / t_esc**

外部からの入力(L_src)なしに**貯蔵と放射を同時に増やさない**(E_res を増やせば L_out は減り、放出で L_out が増えれば E_res は減る)。内蔵の 🐮 `lfbotTrap`(第265便d)の既存の機能との対応は次のとおり(**対応づけの表であって、本便は 🐮 を 1 バイトも変えていない**):

| 帳簿の量 | 🐮 lfbotTrap の既存の量 |
|---|---|
| E_res | E_γ(減光で外へ出なかった自光の貯蔵) |
| f_trap L_src | 減光 lightSweep(ℓ≈1)が外へ出さなかった自光 ℓ·Λ(熱から引き取る —— `supply`) |
| t_esc | `tEsc`(蓄積期 40)→ `tEscCollapse`(崩壊の後 0.4)—— コアの shed の発火で切り替える |
| L_out(放出分 E_res/t_esc) | L_esc(E_esc に積む) |
| 帳簿の閉じ | E_s + E_γ + E_esc + Q − E_in = E_s(0)(E_in を落とすと二重計上) |

🐮 は**自光だけ**を溜める(外来光の捕獲は無い)・青方偏移に上限が無い・`thermal:"tint"` 専用という限界を持つ(PHYSICS §6 の 🐮 の行)。L_loss の明示の口座と f_trap の宣言は次段の決断事項候補である。

## 5. 力学の DR と光学のトイは別の物

- 💮 `clusterAnalogyBH`・🌚 `galaxyAnalogyBH` の DR は**力学の質量要素の代表粒子**(`massLedger.darkRotor.lens:"excluded"`)。
- 🐮 `lfbotTrap` は**光学の減光と放出のトイ**。
- 両者は**同じ物体の証明ではない**(同じ DR の別の面を示したとは言わない)。
