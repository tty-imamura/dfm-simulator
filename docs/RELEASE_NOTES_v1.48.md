# RELEASE NOTES v1.48 検証版(RC)

**v1.48 は検証版(RC)である。** RC は「検証版」の意味であって、較正の完了でも観測一致の主張でもない。
**3σ の門の数は v1.47 から増えていない**(掲載 124 本の較正 4 値は **合 0 / 量限定合 2 / 否 1 / 保留 16** —— `docs/SAMPLE_STATUS.md`。第343便から同じ 4 値)。
**HOLD 6 項の解除宣言は行っていない**(`docs/RELEASE_NOTES_v1.44.md` §4⁶″ をそのまま継ぐ —— 継承は再判定ではない)。
したがってこの版も「**現実較正を完了した**」「**Release した**」とは名乗らない。開発線で足した診断は、どれも**候補を並べた表**であって、採る型の結論ではない。

**更新の前に**: 公開版と beta は、同じ端末の保存領域(セーブ・設定)を共有する。大きな更新の前に、「データ管理」から JSON の書き出しでバックアップを取ることを勧める。

### 1″. 分かっている限界

- 出典を開けない AI チャットでは、実在の天体は実単位の本にならない(近似のトイのまま —— その旨が 1 行で出る)。
- 観測レコードから組み立てた本で見ているのは、自己診断の周期(±1%)だけで、観測との照合の結果ではない。
- 「短縮版をコピー」は、仕様を `docs/AI_SPEC.md` へのリンクで渡すので、リンク先のページを読める AI チャット向け。ページを読めない AI チャットには「1回で生成するプロンプト」の「生成用プロンプトをコピー」(仕様を全部含む)を使う(原仮定者の実機の確認(2026-11-27): リンクを読めない AI チャットでも「生成用プロンプト」なら作れた・短縮版は読めなかった)。画面の上で「短縮版はリンクを読める AI 向け」と見分けられる表示は、次のアプリの便で足す。
- 以前の版で保存した API キーと設定の掃除は、**開いた場所ごとの保存領域**に働く。公開のサイトで保存したキーは、公開のサイトの公開版(パスに `/beta/` を含まない道)を開いたときにアプリが消す(beta のページを開いただけでは消えない)。html のファイルを端末に置いて直接開いて使っていた場合、その保存領域は公開のサイトとは別なので、公開のサイトを開いても消えない —— 同じ置き場所で新しい版の html(置き場所のパスに `/beta/` を含まないもの)を開くと、アプリが消す(ブラウザによっては、ファイルの置き場所ごとに保存領域が分かれる)。心配なときは、ブラウザの「サイトのデータを消す」でも消せる。**キーそのものの失効は、提供元の画面で行う**(アプリからはできない)。
- 一様重力を持つ内蔵の本のうち 4 本(♨️ 対流・🧪 浮力・☕ 冷却・🧬 創発)に、v1.47.0 より前のセーブを取り込んで開くと、重力の向きが今の配置に対して逆になる(v1.47.0 にも在る動き)。取り込みのときに案内が 1 文出るが、本の値は変えない —— 当時の見え方にするには、共通設定の「視点の傾き θ(°)」を −90 にする(README)。内蔵の本を指す旧いセーブにだけ別の案内を足すのは、次のアプリの便。

## 3. root で SKIP する試験(昇格の後の root の QA の範囲)

昇格の後の root のフル QA は **__SKIP_ROOTPASS__ 件 PASS・SKIP __SKIP_LINES__ 行**(1 行に複数の試験を並べる SKIP があるので、試験の数で **__SKIP_TESTS__**)。
**SKIP のうち __SKIP_BETAPASS__ は beta だけの門(`TARGET.startsWith('beta/')` ほか)や「適用の前の世代」を見る門の試験**で、同じ html(root と beta は byte 同一)の beta のフル走行で PASS している。
残り __SKIP_OLDN__ 件(__SKIP_OLDNAMES__)は**廃止した本・属性を読む旧い試験**で、beta でも走らない。
第357便の鍵(掃除 `behavior.apiKeyCleanup357b`・対話式の入口・観測レコードの道・新しい本 2 本 ほか)は、root では beta だけの門で SKIP のまま —— beta の走行で数える(`behavior.apiKeyCleanup357b` は、同じ html をパスに `/beta/` を含まない所へ写して開き、公開版の道の掃除も見る)。戻り止め `lint.noApiRoute357b` は root でも走る(昇格の後の root は外へ送る呼び出しを持たない版)。
**root のフル QA の件数だけで第357便までの新機能をすべて試したとは言わない** —— 新機能の試験は beta の走行で数える(v1.45〜v1.47 の §3 と同じ読み)。
