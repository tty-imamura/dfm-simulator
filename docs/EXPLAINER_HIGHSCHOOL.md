# シンプルな仮定から、物理は「創発」する — 決定力場モデル入門(理系高校生向け)

対象: 高校物理(力学・円運動・万有引力)を学んだ人
これは**本物の物理学ではなく、「仮定の物理法則」の思考実験**です。

本書のテーマは一行で書けます。

> **シンプルな決定力場モデル(DFM)を仮定すると、様々な現実物理の"類似現象"が勝手に生まれる(創発する)。アプリで確かめてみよう。**

重力の法則も、熱力学の法則も、相変化も、宇宙膨張も、最初から数式として入れてはいません。
入れたのは「座標は多数決で決まる」というたった1つの発想から出た、少数のルールだけ。
それでも画面の中には、万有引力・時間の遅れ・熱平衡・融解の潜熱・沸騰・分子・銀河の回転・
赤方偏移に**そっくりな現象**が現れます。どこまで本物に似て、どこから似ないのか —
その境界線ごと、ブラウザで動くシミュレータで自分の手で確かめられます。

シミュレータ: `https://tty-imamura.github.io/dfm-simulator/`(iPhoneでOK。開発版は `/beta/`)
公理・数式・機械検証の正本は英語論文2本(基本法則編・箱宇宙編 — リポジトリ `paper/`)です。

## 1. 出発点: 宇宙に星が1つだけだったら

宇宙にたった1つの星しかないとします。「その星は動いている」と言えるでしょうか?
「動く」とは「何かに対して位置が変わる」こと。比べる相手がなければ決められない気がします。

ニュートンは**バケツの思考実験**で「絶対空間」という見えない基準を立てました。
19世紀の**エルンスト・マッハ**は噛みつきます — 「水面がへこむのは宇宙中の星々に対して
回転しているからだ。宇宙が空っぽなら回転そのものが無意味だ」(**マッハ原理**)。
この模型宇宙は、マッハの側に全振りしたルールでできています。

## 2. 仮定はこれだけ — DFMのルール

1. **決定力 W**: 空間はあらかじめ存在しない。各地点の「座標の決まりやすさ」を
   w = 質量 ÷ 距離(m/d)の総和で表す。**決定力とは、その場所で「どちらが止まっているか」を
   決める投票権**であり、質量が大きく距離が近いほど票数が多い。遠い宇宙全体の寄与は
   背景決定力 **D₀** という1つの値にまとめる。
2. **坂を上がる**: 質点は決定力の坂を高いほうへ加速する。
3. **静止の多数決(引きずり)**: 各地点の「静止」は、まわりの質点の運動の
   決定力重みつき平均。巨大な星や回転円盤のそばでは、空間ごと引きずられる。
4. **時計と光は ψ ひとつ**: W が高い場所ほど時計が遅れ、光は「進みにくい」ほうへ曲がる。
   どちらも1つのスカラー量 ψ から出す。
5. **熱は内部の量**: 粒子は内部温度(または自転)を持ち、接触でやり取りする。
   温度は**熱圧(E5′)**という斥力としてだけ力学に入る。
6. **接触と結合**: 粒子は重なれば押し返し、条件により短距離の結合・凝集の分子間力を持つ。
7. **箱(オプション)**: 遠い宇宙をまとめた「箱」の決定力が時間とともに薄まる=宇宙膨張。

以上です。以下のカタログの現象は、**すべてこのルールたちの帰結**として画面に現れます。

## 3. 創発カタログ — アプリのどのサンプルで、何が確かめられるか

それぞれ「✅確認できること」「⚠️できないこと・違うこと」を明示します。
この境界線を隠さないのが本模型の流儀です。

### 3-1. 万有引力の逆二乗則(🪐 土星の環 ほか天体サンプル全般)

w = m/d の坂の傾きは m/d² に比例します。「決定力の傾き=力」というルールを置いただけで、
**万有引力の逆二乗則が勝手に出てきます**。重力の法則を仮定していないのに、です。
- ✅ 軌道運動・環の維持・二体/三体の運動(🌍地球と月は実際の質量比・同期自転で較正)
- ⚠️ 逆二乗は2次元の模型なので厳密には「2Dの重力」ではなく3D式の借用。一般相対論の
  強場(ブラックホール等)は範囲外

### 3-2. 慣性の基準 — ニュートン vs マッハ(🪣 マッハのバケツ)

D₀ スライダー1本が300年の論争の縮図です。
- ✅ D₀=0: 回転リングの内側の空間が一緒に回る(純マッハ)。D₀ 大: 遠い宇宙の多数決が
  勝ち、ほぼ絶対空間(ニュートン)になる — 連続的につながる
- ⚠️ 本物の宇宙の D₀ に相当する値は測れない(思考実験の道具)

### 3-3. 空間の引きずりと銀河の回転曲線(🌌 銀河の回転曲線・🌀 単独ロータ)

内側の星たちが空間ごと回すおかげで、外側の星は少ない引力でも速く回り続け、
**回転曲線がダークマターなしで平坦になります**。おすすめA/Bで引きずりオン/オフを
同時比較できます。
- ✅ 引きずりが強い宇宙「なら」平坦化する、という機構のデモ。運動量・角運動量は
  反作用込みで厳密に保存(保存量モニタで確認可)
- ⚠️ **実宇宙の主張ではありません**。本物の引きずり(レンズ=サーリング効果)は微弱で、
  ダークマターには回転曲線以外の独立証拠が多数あります

### 3-4. 時間の遅れ・光の湾曲・シャピロ遅延(🛰️ 弱場GR較正・🔭 重力レンズ・☿ 水星)

ツマミ Kt を現実の値(光速²÷重力定数)に合わせると:
- ✅ GPS衛星の時計 **+38.5μs/日**・太陽をかすめる光の偏向 **1.75秒角**・シャピロ遅延
  **約281μs** の3つが、1つの ψ から同時に数値まで一致
- ⚠️ 基本ルールのままでは**水星の近日点移動(100年で43秒角)は出ません**。時計の式 ψ を
  運動の法則に格上げする明示的な拡張(E12 測地線モード)をオンにしたときだけ再現します —
  「どこまで合って、どこから合わないか」を数字で示す好例です

### 3-5. 熱力学の基本法則たち(🔥 熱平衡・📏 熱伝導・🌈 放射冷却・♨️ 対流・🧪 浮力)

- ✅ 温度の違う集団が接触で同温になる(熱力学第0法則的な熱平衡)。熱は近いほど速く
  伝わる(伝導)。高温ほど速く冷える(放射)。床を加熱すると熱圧と重力の競合で
  **対流セルが自発的に回り出す**。軽く熱い粒子が持ち上がる(浮力)
- ⚠️ 熱の「圧力」は分子運動論ではなく熱圧(E5′)という仮定のルール。定量的な気体定数や
  実在物質の物性は範囲外

### 3-6. 潜熱と相変化(🫠 融解・❄️ 凝固・🔁 融解⇄凝固)

エンタルピー(熱の総量)を正本にすると、**温度が融点でピタリと止まる「プラトー」**が
自然に出ます。止まっている間、注いだ熱はすべて相変化(潜熱)に使われています。
- ✅ 融解前線が加熱面から進む・凝固で結晶の秩序が創発する(無秩序な液体 ψ6≈0.8 →
  凍ると 0.97)・往復してもヒステリシスがない・エネルギー帳簿が閉じる(保存量モニタ)。
  粒子の白い円弧=溶融度なので、温度色と別チャンネルで相が読めます
- ⚠️ 過冷却・確率的核生成は未実装。実在物質の融点・潜熱の数値再現はしない

### 3-7. 沸騰 — ただし「浮力なし」の宇宙で(💨 沸騰と凝縮)

- ✅ 沸点で2つ目のプラトー。蒸発は凝集エネルギーも支払う(実効蒸発潜熱)。二相共存の
  準定常。**この宇宙の気体は液体と同じ粒子質量なので密度浮力がなく、蒸気は加熱床と
  液の間に溜まって液を持ち上げる — 膜沸騰(ライデンフロスト)類似**が創発します
- ⚠️ 「軽い気泡が浮かんで上がる」通常の沸騰にはなりません(それには密度差が要る)。
  見た目を気泡浮力と誤解しないよう説明文でも明示しています

### 3-8. 分子と物質構造の創発(⛓️ 鎖の液体・🧬 三態の創発)

ここが最新の見どころです。
- **⛓️ 鎖の液体**: 液体の結合に「結合価2」(相手は2つまで)という制限を入れると、
  固体=結合数無制限の塊 ⇄ 液体=**鎖(分子のスパゲッティ)** という構造の相転移が
  出ます。融解は配位6の結合網を配位2の鎖へ組み替えるコストを潜熱として支払う —
  等方の液体より目に見えて融けにくい
- **🧬 三態の創発**: さらに進めて「相のスイッチ」を全部捨て、**結合の予算**だけを
  仮定します(各分子は結合予算を相手の数で分け合う。結合数が減ると残りが強くなる。
  結合相手は固定せず幾何で毎瞬決まる)。すると熱圧との競合だけで、固体(配位6の格子)→
  液滴群 → **分子ガス**(2〜9粒の小クラスタが飛び回る)が創発します。最後の結合が
  いちばん強いから、バラバラの原子でなく「分子」の気体になる — 結合線の表示が
  太く濃くなっていく様子でそれが直接見えます
- ✅ 結合数が徐々に変わる様子・構造(塊/鎖/分子)の創発・エネルギー帳簿の閉鎖
- ⚠️ 実在の高分子・化学結合の定量再現ではない。電荷・双極子は未導入(鎖の成立には
  結合の数の制限だけで足りた、というのがこの模型の発見です)

### 3-9. 宇宙膨張と赤方偏移(📦 箱宇宙シリーズ・🧭 ２つのH推定器)

- ✅ 膨張で銀河が離れる・光の波長が伸びる(赤方偏移)・束縛系は膨張しない。
  **🧭では同じ宇宙を2つの方法で測ると膨張率の答えが約8%割れる** — 測る側が仮定した
  公式が実際の法則と違うため。実宇宙の**ハッブルテンション**(約9%の食い違い)と
  同じ水準に較正してあります
- ⚠️ その一致は「大きさを合わせた」だけで、実宇宙のテンションの説明ではありません
  (画面の注意書きもそう言います)

### 3-10. 恒星の点火(⭐ 恒星コア)

- ✅ 重力収縮 → 中心が高温高密度 → 融合で熱を放出 → 放射で輝く、という恒星の
  エネルギー物語の骨格。融合を切った対照実験と比べると放射エネルギーが約75倍
- ⚠️ 核物理の実際の反応率・恒星構造論の定量は範囲外

## 4. まとめの表 — どこまで本物で、どこから仮定か

| 話題 | 本物の物理 | この模型 |
|------|-----------|----------|
| 逆二乗の重力 | 法則として与えられる/一般相対論から導出 | 「決定力の傾き」から自動で出る ◎ |
| 慣性の基準 | 絶対空間〜部分的にマッハ的 | 完全に多数決。D₀ で両者を連続につなぐ |
| 空間の引きずり | 実在(レンズ=サーリング)だが極めて微弱 | ツマミで自由に強くできる(ここが「仮定」) |
| 平坦な回転曲線 | ダークマターで説明(独立証拠多数) | 強い引きずりで再現(模型内の話) |
| 時間の遅れ・光の湾曲 | 一般相対論で確立 | 1つのスカラー場から同形の式(弱場で数値一致) |
| 熱と圧力 | 分子の並進運動と衝突 | 内部温度+熱圧(仮定のルール) |
| 潜熱・相変化 | 分子間力と統計力学から | エンタルピー正本+分子間力の帰結として創発 |
| 分子 | 量子力学の化学結合 | 結合の予算/結合価という古典ルールで類似構造が創発 |
| 宇宙膨張 | 一般相対論+観測(FLRW) | 箱の決定力の減衰として1ツマミ化 |
| 保存則 | 厳密 | 運動量・角運動量・エネルギーとも帳簿込みで機械検証(QA) |

## 5. アプリの歩き方

1. 画面上のカテゴリ選択で「熱の実験室」など分野を絞れます。サンプルを開いたら
   **説明タブ**を読む — 「📌要約 / 🔎観察 / 🎛操作」の3部構成で、何を見るべきかが
   書いてあります。
2. **おすすめA/B**があるサンプルはワンタップで対照実験(引きずりあり/なし等)が
   上下2画面で同時に走ります。
3. **保存量モニタ**(表示カテゴリでON)は運動量・角運動量・エネルギーの帳簿を
   リアルタイム表示します。「創発」がごまかしでないことの検算です。
4. パラメータはすべて編集できます。壊れたら「⏮初めから」でリセット。
   相変化サンプルには専用ノブ(融点・潜熱・結合など)もあります。
5. すべての主張は機械QA(300項目超)で毎版検証されています(`tests/`)。
