## 1. 4 値の定義(宣言であって閾値ではない)

| 値 | 条件 |
|---|---|
| **合** | その系の **σ を持つ判定量がすべて** 3σ の門(`|y_sim−y_obs| ≤ 3σ+ε_num` かつ `ε_num ≤ 0.3σ`・dt 3 段+正の観測次数)を通った |
| **量限定合** | σ を持つ判定量の**一部だけ**が 3σ を通った(通らない量が同じ系に残っている) |
| **否** | 3σ を外した量が 1 つ以上ある |
| **保留** | **判定できない** —— σ 未接続 / 写像未確定 / 数値精度 / 条件不一致 / 未測定 のいずれか |

**保留は物理仮説の否定ではない。** 「まだ測っていない」「まだ σ を繋いでいない」「測っている量と
観測の量の対応がまだ確定していない」という**手続き上の状態**である。
逆に、**±1% の目安に入ったことは観測一致ではない**(σ を持たない量の「合」は目安合である)。

### 5.2 h8 検査点(⚡ 1 系・dt/8=0.002 まで)

⚡ だけ 4 段(dt, dt/2, dt/4, dt/8)を走らせた(11,083,772 步・19.5 s)。**他の 3 系は未走行である。**

**読み取れること 3 つ**:
1. **周期と離心率は漸近域に居る。** 観測次数が段をずらしても 1.000 のまま(p≈1)で、
   `|Q_h−Q_{h/4}|` は**上限ではなく** ×4/3 して初めて粗い側の誤差になる(72.70 s → 96.95 s)。
2. **近点移動は漸近域に居ない。** 観測次数が 2.05 → 0.88 と**段をずらすと変わる**。
   3 段だけで測った p_obs=2.05 を収束次数として使ってはいけなかった —— **h8 で初めて分かった**。
   (門の判定は元から `数値未解決` なので、判定は動かない。動いたのは「なぜ言えないか」の理由である。)
3. **h→0 の外挿は観測の近くへ行くが、届かない。** 周期の Richardson 外挿 8834.3155 s は
   観測 8834.534723 s の **−0.219 s(−2.48×10⁻³%)**で、**σ=2.5×10⁻⁷ s に対して 8.75×10⁵σ** である。
   **外挿は走行ではない**(推定値である)。**「dt を細かくすれば合う」とは書けない** ——
   この外挿が正しければ、dt→0 でも 0.22 s 残る。

門が要求する**予算 0.3σ(=7.517×10⁻⁸ s)の 9.67×10⁸ 倍**である(同じ事実の 2 通りの書き方)。
**予算で打ち切ったのではない**(⚡ の 4 段はすべて時間予算内で完走した)——
**打ち切りと失敗を混同しない**。足りないのは計算時間ではなく、この積分器のこの窓での桁である。

## 7. 書いてよいこと・いけないこと

**書いてよい(すべて本文書の実測)**:
- 3σ の門を通った量は **2 件**(✨ α Cen AB・🌟 Sirius AB の公転周期)であり、**証拠付き予測は 0 件**である。
- 3σ を外した量は **2 件**(✴️ 25.95σ・💫 210.3σ)である。
- **条件不一致 8 行を隔離した**。対照条件の走行は行われていない。
- **✴️ は kFrame ≤ 0.0885 なら 3σ に入る**が、**💫 は kFrame=0 でも 3.61σ で入らない**。
- NS 連星の近点移動は **deg/yr でも °/周 でも観測の約 2 倍**である(🧿 を除く。🧿 は fit 対象)。
- ⚡ の周期・離心率は漸近域に居る。**近点移動は h8 で漸近域に居ないことが分かった。**

**書いてはいけない**:
- 「現実較正が完成した」「較正完了」「どのサンプルも完成した」。**完成は 0 本である。**
- 「予測が成立した」。**証拠付き予測は 0 件である。**
- 「保留=否定」。保留 36 本は**判定できない**という意味であって、物理仮説の否定ではない。
- 「近点移動が観測と合った」「NS 連星の数値精度が足りた」。
- 「単位を直せば比 2 は消える」。**deg/yr でも 2.04〜2.12 である。**
- 条件不一致 8 行を「対照が合っていた」と読むこと。**対照の走行そのものが無い。**
