## 1. 4 値の定義(宣言であって閾値ではない)

| 値 | 条件 |
|---|---|
| **合** | その系の **σ を持つ判定量がすべて** 3σ の門(`|y_sim−y_obs| ≤ 3σ+ε_num` かつ `ε_num ≤ 0.3σ`・dt 3 段+正の観測次数)を通った |
| **量限定合** | σ を持つ判定量の**一部だけ**が 3σ を通った(通らない量が同じ系に残っている) |
| **否** | 3σ を外した量が 1 つ以上ある |
| **保留** | **判定できない** —— σ 未接続 / 写像未確定 / 数値精度 / 条件不一致 / 未測定 のいずれか |

**保留は物理仮説の否定ではない。** 「まだ測っていない」「まだ σ を繋いでいない」「測っている量と
観測の量の対応がまだ確定していない」という**手続き上の状態**である。
逆に、**±1% の目安に入ったことは観測一致ではない**(σ を持たない量の「合」は目安合である)。

| (2) 時系(窓が張る実時間) | 全段で同じ近点数・1.07×10⁶〜1.72×10⁷ 步 | 4.41×10⁶〜3.54×10⁷ 步 | 段が細かいほど步数だけが増える |
| (3) 近点抽出 | 20/20 検出・unwrap の跳び 0 | 20/20 検出・跳び 0 | 全段で窓が埋まった(予算で切れていない) |
| (4) **質量の丸め**(`S.m` が Float32) | ΔP=**5.398×10⁻⁵ s = 215.5σ** | ΔP=**2.175×10⁻⁴ s = 251.7σ** | P ∝ M^(−1/2) で M の相対誤差の半分が P に乗る |

**(4) は (1)〜(3) とは別の出どころで、桁が 6 つ違う。** ⚡ の離散化誤差 ε_num は 72.704 s
(**2.90×10⁸σ**)で、質量の丸め **215.5σ** の **約 1.3×10⁶ 倍**である。
**したがって「Float32 の質量が精度を決めている」とは書けない** —— 決めているのは離散化である。
逆に、**質量を double にしても ε_num は 1 桁も動かない**(この診断はそれを言うためにある)。
**`S.m` を Float64 にするかどうかは、この結果では決まらない**(決断事項として残す)。

## 7. 書いてよいこと・いけないこと

**書いてよい(すべて本文書の実測)**:
- 3σ の門を通った量は **2 件**(✨ α Cen AB・🌟 Sirius AB の公転周期)であり、**証拠付き予測は 0 件**である。
- 3σ を外した量は **2 件**(✴️ 25.95σ・💫 210.3σ)である。
- **条件不一致 8 行を隔離した**(第258便d)。**第259便d でその 8 行の対照走行を行った**(§3.1・8/8)。
- **✴️ は kFrame ≤ 0.0885 なら 3σ に入る**が、**💫 は補正質量 f を維持したまま kFrame=0 にしても 3.61σ で入らない**。
  **f=1(観測質量)+ kFrame=0 の対照は 0.27σ** である(§4.1)。
- NS 連星の近点移動は **deg/yr でも °/周 でも観測の約 2 倍**である(🧿 を除く。🧿 は fit 対象)。
- ⚡ の周期・離心率は漸近域に居る。**近点移動は h8 でも h16 でも漸近域に居ない。**
  **🧶 は 3 量とも漸近域に居る**(⚡ と 🧶 でふるまいが違う)。
- **記録器あり・記録 0 件**である(証拠付き予測の枠は作った・中身は空)。
- **分類変更で ⭕📶📐 の 3 本を原理実証へ移した**(40 本 → 37 本)。**不足は 1 つも解決していない。**
- **質量の丸め(`S.m` は Float32)だけの寄与は ⚡ 215.5σ・🧶 251.7σ** で、離散化 ε_num の
  約 10⁻⁶ 倍である —— **精度を決めているのは離散化であって質量の型ではない。**

**書いてはいけない**:
- 「現実較正が完成した」「較正完了」「どのサンプルも完成した」。**完成は 0 本である。**
- 「予測が成立した」。**証拠付き予測は 0 件である。**(記録器が空であることを「予測が 0」と混ぜない。)
- 「保留=否定」。保留 33 本は**判定できない**という意味であって、物理仮説の否定ではない。
- 「近点移動が観測と合った」「NS 連星の数値精度が足りた」。
- 「単位を直せば比 2 は消える」。**deg/yr でも 2.04〜2.12 である。**
- 条件不一致 8 行を「対照が合っていた」と読むこと。**対照走行の残差が小さいことは観測一致ではない**
  (太陽系 16 本は σ が門に 1 本も繋がっていない)。
- **「分類変更で不足が解決した」。** 数える母集団を変えただけである。
- 「💫 は観測質量そのものが σ 予算を超えている」。**超えるのは補正質量を維持したときである。**

  **🧶 の外挿は観測から 1.84×10⁷σ 離れている。**
- 「質量を Float64 にすれば精度が足りる」。**離散化の 10⁻⁶ 倍の寄与である。**
