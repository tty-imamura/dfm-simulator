## 1. なぜ「重力だけ」では足りないか

本モデルの重力は E4 `a = −G Σ m_j (r−r_j)/(d²+ε²)^{3/2}`、その素になる決定力は
E1′ `w_j = m_j/√(d²+ε²)`(Plummer 型)である。したがって **中心に十分重い点を置くだけで
Φ = −GM/√(r²+r_c²) は既に得られており、それは「ブラックホール」ではない** —— 星でも
ダークローターでも同じ形だからである。BH と呼ぶには、重力とは**別の条件**が要る:

| 条件 | 本モデルでの担い手 | 状態 |
|---|---|---|
| (a) 光が出て来にくい(遅れ・赤方偏移) | E8R の n_eff=e^{2κW}(屈折率) | **既に在る**(§6-1) |
| (b) 光が出て来られない(捕捉境界) | E8R の随伴項 **u_r < −c_eff** | **内向きメッシュ流が要る**(§6-2) |
| (c) 暗い(自光の掻出) | 減光 lS_eff=min(1,\|s\|R/c_surf) | **既に在る**(🕳 ダークローター) |
| (d) 物質・光を**受け取って増える** | 捕獲判定+合体帳簿 | **本便で規約を定義**(§5) |
| (e) 中心天体としてまわりを支える | 有限コア Φ_c + メッシュ角運動量 | **設計のみ**(§4・§7) |

**(a)(b)(c) は独立の条件である**。本便の実測では 🎐 の中心は (a) を持ち、(c) は 0
(spin=0 宣言)、(b) は与える u_r 次第で在ったり無かったりする(§9)。

## 4. 最小の力学コア Φ_c

```
Φ_c(r) = − G·M / √(r² + r_c²)        (phiCore)
g(r)   = dΦ_c/dr = − G·M·r / (r² + r_c²)^{3/2}   (gCore)
```

- r ≪ r_c: Φ_c ≈ −GM/r_c·(1 − r²/2r_c²) —— **中心で調和**。角振動数
  ω₀ = √(GM/r_c³)(`coreHarmonicOmega`)。中心で力が 0 に戻るので特異点を持たない。
- r ≫ r_c: Φ_c → −GM/r —— **遠方でニュートン**。
- **これは新しい力ではない**。E1′ の w=m/√(d²+ε²) と E4 がすでにこの形で、
  設計の中身は「ε を数値の都合ではなく **r_c という構造長として宣言する**」ことだけである。
  どちらの読みを採るか(ε を据え置いて別キー r_c を足すか、ε に意味を持たせるか)は
  **決断事項**(§11 (1))。
- **重力だけでは BH と呼べない**(§1)。Φ_c は土台であって定義ではない。

## 5. 捕獲と合体の帳簿規約

### 5-1 捕獲判定(**半径条件とエネルギー条件は別**)

- **半径条件** `captureByRadius(rel, R_cap)`: |X_rel| ≤ R_cap。R_cap に何を採るかは宣言
  (R_core / 捕捉境界 / 別の値)。
- **エネルギー条件** `captureByEnergy(rel, p, R_core)`: **束縛(E<0)かつ近点 ≤ R_core**。
  近点は Plummer 有効ポテンシャルの折返しを二分して出す(`pericenterPlummer`)。
  **E<0 だけでは捕獲ではない**(連星になるだけ)—— 2 つを分けて返す。

### 5-2 合体の帳簿(`mergeLedger`)

**粒子を消して終わりにしない**。宣言は次の 6 つで、**どれも導出ではない**:

1. `M_rest' = M_a + M_b`(厳密加算)
2. `P' = P_a + P_b`(厳密加算)・`X'` = 静止質量重心
3. `f_M'` = 静止質量重み平均 → `M_grav' = f_M'·M_rest'`
4. `R_core' = (R_a³ + R_b³)^{1/3}`(体積加算の宣言)
5. 重心まわりの軌道角運動量 L_orb を `spinFraction` で `J_spin'` と `J_mesh'` へ分ける
   (既定 0 = **全部メッシュへ**)。**全角運動量は構成的に厳密保存**する。
6. `E_core' = E_core,a + E_core,b + coreBinding·U_pair`(U_pair は E1′ と同じ軟化の対ポテンシャル)

そのうえで **残余 E_res = E_before − E_after を `Q'` へ入れる**。

- **E_res < 0 なら `ok:false` を返して合体を拒否する**。呼び出し側は宣言(coreBinding 等)を
  やり直す。**後から clamp しない**(clamp は帳簿を黙って壊すため)。
- 既定の宣言(coreBinding=1・spinFraction=0)では E_res = ½μ|Δv|²(重心系の相対運動エネルギー)
  に**厳密に一致**する。実測は §9-3。

## 6. 光の 3 条件 —— 逃げにくさ・減光・捕捉境界

### 6-1 逃げにくさ(既に在る)

E8R: `n_eff = e^{2ψ}`、`ψ = κ·W`、光線 `dr/dt = (c₀/n_eff)·ĉ + u`。
径方向の局所光速は **c_eff(r) = c₀·e^{−2κW(r)}**(`cEff1`)。孤立点質量(D₀=0・r_c→0)では

```
c_eff(r)/c₀ = e^{−r_s/r} ,    r_s ≡ 2κM   (κ=G/c₀² なので r_s は Schwarzschild 換算半径)
```

**r=r_s でちょうど e^{−1}=0.367879… であって 0 ではない**。指数形なので **有限の r で 0 に
ならない** —— これが本モデルと GR の**構造的な違い**である(比較はしていないが、
「地平面を再現した」と書けない理由がここにある)。到達時間の遅れ倍率は `escapeDelayFactor`。

### 6-2 捕捉境界の定義候補(`captureBoundary`)

```
ṙ(r) = u_r(r) + c_eff(r) = 0        ← 外向きの光でも右辺が 0 になる r
```

- **u_r ≡ 0(静止コア)では根が無い**(c_eff>0 が有限の r で 0 にならないため)。
  → **捕捉境界は屈折だけからは出ない**。内向きのメッシュ流が要る。
- 自由落下を宣言した内向き流 `u_r = −√(2GM/√(r²+r_c²))`(`freeFallInflow`)を入れると
  **閉形式**が出る。s ≡ √(r²+r_c²) と置くと √(r_s/s) = e^{−r_s/s} ⇔ x = e^{−2x}(x=r_s/s)
  ⇔ 2x·e^{2x} = 2 なので x = W(2)/2(Lambert W)。したがって

```
s_cap / r_s = 2 / W(2) = 2.345750755…        (M にも c₀ にも依らない — freeFallBoundaryRatio)
```

- **この u_r は設計候補の入力であって、プリセットが走らせている場ではない**
  (🎐 は kFrame=0 で引きずり項が働かない)。「捕捉境界を実装した」とは書かない。

### 6-3 減光(既に在る・別条件)

🕳 ダークローターの ② 自光の掻出 `lS_eff = min(1, |s|·R/c_surf)`(`sweepDarkening`)。
**捕捉境界でも逃げにくさでもない第三の条件**である(第37便 D1 が ②③ の分離を実証済み)。

## 7. 完成への順番(この順でしか測れない)

1. **単一コアの有限収支** —— Φ_c 単体で、静止した 1 コアの M/P/J/E が窓の中で閉じる。
2. **自由二体と合体収支** —— pinned を使わずに 2 コアを回し、§5 の帳簿で合体させる。
   残余の符号検査が通ること(拒否経路が実際に発火することを含む)。
3. **中心コア+ガウス集団** —— 3D 正規分布を定常分布に持つ集団を中心コアのまわりに置く。
   ここで初めて「星団・銀河の中心天体」の面が測れる。
4. **光の伝播と捕捉** —— 上の系で E8R の光線を撃ち、c_eff・逃げにくさ・(u_r があれば)
   捕捉境界を測る。

## 10. 渦巻パターン腕と棒(`tests/out/armbar-w274e.json`)

第64報の順番「腕単体 → 楕円銀河の回転と組む → 棒」の**設計の初版**。
**形を外から指定するもの**であり、「腕の創発」「棒の自己組織化」は**主張しない**。

### 10-1 パターン腕

```
U_arm = A(r)·{1 − cos(m·χ)} + ½κ_z·z² ,   χ = φ − Ω_p·t − b·ln(s/r₀) ,  s = √(r²+r_min²)
A(r)  = A₀·(r/r_d)·e^{−s/r_d}     (先頭の r は丸めない ⇒ A(r)/r が有界 ⇒ 中心で横力が発散しない)
−∇U:  ∂U/∂r = A′(r)(1−cos mχ) + A(r)·m·sin(mχ)·(−b·r/s²) ,  (1/r)∂U/∂φ = [A(r)/r]·m·sin(mχ)
```

- **−∇U と中心差分の最大差 3.087×10⁻¹⁰**(60 点)。**A′(r) 項を落とすと最大 2.169×10⁻¹**・
  **∂χ/∂r 項を落とすと最大 4.487×10⁻¹** ずれる —— どちらも**落としていない**。
- 横幅(小振幅)**σ_⊥² = Θ·r²/(m²·A)**。厳密ポテンシャルの Boltzmann 分散との比は
  Θ/A = 0.5→1.236497 / 0.2→1.065904 / 0.05→1.013152 / 0.01→1.002524 / **0.002→1.000501**
  (小振幅で解析形へ収束する。**大振幅では 24% ずれる**ので、そのまま使わない)。
- パターンのピッチ角(漸近)= atan(1/|b|) = **18.434949°**。**t を変えた振れ幅 2.546×10⁻¹⁰°**

## 13. 自転軸とパワーボール(第275便e — 原仮定者の裁定(第65報)(7)(8))

本節は**設計の追記**である。§12 の `api` ブロックは第274便e の 3 本の lib の export だけを載せる契約なので、
本節で触れる `tests/lib-w275e-powerball.mjs` の export はそこに**足さない**(照合の対象が別だからである)。

**13.1 軸の状態は「宣言」と「力学」を名前で分ける。** §2 の共通状態は角運動量を `J_spin`(殻スピン)と
`J_mesh`(空間メッシュ)の**別口座**にしている。第275便e はそこに**軸の向き**を 3 つの宣言として足した:
**傾き角 θ(`core.tilt`・既存)・面内方位 φ₀(`core.azimuthDeg`)・歳差角速度 Ω_p(`core.precessionRate`)**。
これらは **prescribed(規定運動)** であって、トルクから出た量ではない。面内成分を宣言どおり回すのに要る
角力積は**面外**(x,y 軸まわり)なので 2D の `L_z` 帳簿には現れず、「**宣言した拘束**が持ち去った量」として
負号で別口座(`axPrescLx`/`axPrescLy`/`axPrescE`)に記帳する。**これは 3D の実装ではない**
(エンジンの力学が読むのは従来どおり z 射影 `J_z` だけである)。

**13.2 dynamic モード(未実装・設計のみ)。** トルクで軸が動く版を入れるには、**軸を倒す仕事の供給源**を
先に決める必要がある。候補は §2 の 3 口座 —— (a) 公転 E/J(`J_orb`)・(b) 収縮 −½Ω²İ(`R_core` の変化)・
(c) メッシュ貯蔵(`J_mesh`/`E_mesh`)。**どれにするかは未決**である(§11 に 決断事項候補 7 として足す)。
決める前に実装すると、第250便c と同じ「対応する仕事なしに回転 E が変わる」帳簿の穴を作る。

**13.3 パワーボール仮説の位置づけ。** 第65報 (8) の仮説(潮汐が軸を傾け自転を加速 → 歳差ロックでさらに加速 →
互いに軸を向ける → 遠心力を失って合体 → 星団中心 → 楕円 → 渦巻 → 棒)は、本設計書の **§5(捕獲と合体の帳簿)**と
**§7(完成への順番)**にそのままは乗らない。閉じた node 模型(`tests/lib-w275e-powerball.mjs`)で測った結果は:

- **軸に垂直なジャイロトルクは自転を加速しない**(τ·ŝ=0 —— |S| の相対漂いは 1.20×10⁻¹⁴)。
  「トルクに逆らう力が回転を加速する」を成り立たせるには、**加速ぶんの供給源を宣言する**しかない。
  実物のパワーボールで回転が上がるのも、手が歳差周波数で仕事をしているからである。
- **向きの散逸は軸を寄せるが、自転は加速しない**(整列の時定数 |S|/Q は K に依らない)。
- **閉じた連星では軸が連結線へ寄るが 22.869° の残差で止まり、分離はむしろ広がる**
  (公転 J の行き先が無いので合体しない)。**§5 の合体帳簿は依然として「宣言」でしか閉じない。**

したがって **§7 の順番は変えない**(① 単一コアの有限収支 → ② 自由二体と合体収支 → ③ 中心コア+ガウス集団 →
④ 光の伝播と捕捉 → ⑤ 観測写像)。パワーボール系列は **②の入口に置く仮説**であって、順番を飛ばす根拠にはならない。
