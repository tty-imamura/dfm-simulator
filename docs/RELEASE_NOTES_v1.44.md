## 1. 何を Release と呼ぶのか(範囲の宣言)

**固定するのは「較正の状態」である。** 具体的には次の 4 つが台帳に載っていること:

| 固定するもの | 値 | どこにあるか |
|---|---|---|
| 慣性(質量)の一次則の不動点 f | **1.999942269345993**(⚡ J0737 で自己無撞着に解いた値・**fit ノブ 0**) | `psrDoubleABDFM.massCalibration`(`law:"inertia-law-lin-v1"`) |
| pull 重みの参照 D₀ᵖ | **3.24204×10⁻⁷ 単位**(=3.24204×10⁸ kg/m²) | 4 系の `physics.D0pull` |
| κ(=G/c₀²) | **7.415555555555556×10⁻⁷**(相対論的連星族 c₀=3×10³) | 4 系の `physics.kappaT` |
| 数値の宣言 | `framePrecision:"double"`・`stateCarry:"double"`・`cmGauge:"barycentric"`・`coupleSink:"core"` | 4 系の `physics` |

**較正に使った観測量は 1 つだけである** —— ⚡(PSR J0737−3039A/B)の**公転周期**。
他の 3 系(🧮 J1757−1854・🩺 J1946+2052・🧶 B1534+12)は**この処方を 1 か所も動かさずに当てた
hold-out** であり、係数をこの 3 系で決め直したことは一度もない(🧶 は第251便a 以降 **凍結 hold-out**)。

## 3. Negative Claims(**この版が主張しないこと**)

1. **NS 連星について 3σ の観測一致は主張しない。** 棚卸しの機械門(`|y−y_obs| ≤ 3σ+ε_num` かつ
   `ε_num ≤ 0.3σ`)を通った NS 連星の量は **0 件**である(第256便d の実測)。止まっているのは 2 か所で、
   どちらも「合わない」ではなく「**まだ言えない**」: (i) 同じ定義の検出器 A/B の広がりが観測 σ_rel より
   大きい、(ii) 既定刻みの離散化誤差 ε_num が観測 σ の予算(0.3σ)を **3×10²〜9.7×10⁸ 倍**超える。
   **dt を 4 段・8 段にしても埋まらない**(1 次収束なら 10⁹ 倍の細分が要る)。
   なお (i) は第256便d ③ の合成軌道検定で「**定義の不一致ではなく軌道の雑音**」と同定された ——
   門の名前(`definitionMatches`)と条件を分けるかは統括の決断事項である。
   **恒星連星(この Release の範囲外)では門が初めて合否を出した**: 観測版 ✨ α Cen AB・🌟 Sirius AB の
   周期が「合(3σ)」(残差 0.096σ / 0.274σ)、**DFM 版 ✴️・💫 が「否(3σ)」(残差 26σ / 210σ)**である。
   **DFM 版が 3σ で否になった事実をこの Release は隠さない。**
2. **近点移動が観測と合ったとは書かない。** DFM/観測の比は 4 系とも **約 2**
   (h/4・窓 20 近点で 2.0014 / 2.0020 / 2.0023 / **2.0258**)。これは較正質量 fM(f≈2)が
   E12 の 1PN チャネルへそのまま入る**較正の従属量**であって、独立な予言ではない。
   **比は obsCard の別欄に出す**(第256便d)—— 数値収束の記録であって一致の主張ではない。
   🧶 の +1.2% の食い違いは離散化誤差(ε_num=0.33%)より大きく、離散化では説明できない
   (第252便a: その差の全部が λ_PN=0 の基線 A0 である)。
3. **`spaceMesh`(空間メッシュ)は本 Release のどのプリセットも宣言していない。**
   第253〜255便の空間メッシュは原理サンプル(🪟🫂🎠)と診断であって、現実較正の経路には入っていない。
4. **λ_PN=1/f 等の経験補正は本体へ自動採用しない**(3 審査 v14 ChatGPT)。候補は variant
   (🪶🪃🪀🪤)としてだけ存在し、本体 4 系の宣言は 1 bit も動かしていない。
5. **周期短縮(ΔP/P)を重力波の再現とは呼ばない。** 既定刻みで測れる短縮は dt にほぼ線形の
   **離散化仕事**で、連続極限で消える(Peters 式との比 8.8×10⁸ は記録であって比較ではない)。
6. **ブラックホール以降はトイモデルである**(原仮定者 第48報)。観測値と「類似」しつつ安定すれば
   よく、**証明しない**。「観測質量を補正した時点で元の計算式を否定している」以上、証明を強めるほど
   反感が増す —— だから BH・星団・銀河の展示は「類似と安定」だけを書く。
7. **星団は本 Release の範囲外である。** 第256便d の対照(C0/C1/Cn)は「中心に BH を置けば安定する」を
   **否定した**(→ 6. と同じ流儀で、否定結果をそのまま載せる)。
8. **「現実較正完了」とは書かない**(第257便d で版名に固定した)。この版が固定するのは
   **較正の状態**(§1 の 4 項目)であって、観測との一致ではない。**DFM 恒星版の 3σ 不合格
   2 件(✴️ α Cen AB 25.95σ・💫 Sirius AB 210.3σ・いずれも「同方向 1 周の公転周期」・
   ε_num は予算内なので数値誤差では説明できない)を台帳に載せたうえで版を切る。**
9. **第256便a の「f=1(観測質量)+ 空間メッシュの織り込み(pairPN)で質量補正が不要になり近点移動も
   解決する」という検証仮説は、実測で不成立である。** f=1・weave off では 4 系とも軌道が成立せず
   (⚡ の e が 0.088→0.823)、f=1・pairPN では Δϖ の DFM/観測比が **6.8 / 11.0 / 3.9 / 108**(⚡🧮🩺🧶)
   と本体の約 2 より遠ざかった。**これは「相対慣性則一般の否定」ではない** —— 否定されたのは
   **この 1 つの実装(対ループへの織り込み・χ 混合・1PN 速度依存項の引数だけを差し替える版)**であり、
   3 審査 v15 が書いた作用・反作用・エネルギーを定義する相対慣性則は**まだ実装していない**。
10. **ブラックホール以降はトイである**(6. の具体化)。この版が BH 以降に求めるのは 3 つだけ:
   **(a) 帳簿が閉じること**(E_tot=K+U+E_shell+E_core+E_mesh+Q+E_escaped・ΔE_tot=W_ext)、
   **(b) 観測されていないエネルギーを許容するが容量は有限であること**、
   **(c) 質量以外の観測量と「類似」すること**。**証明はしない**(観測一致の主張もしない)。

## 4. 何が新しく固定されたか(第256便d)

- **観測レコードの補完**: `paper/data/solar-observations.csv` に ⚡ の ω̇ 行
  (**16.899323(13) °/yr**・Kramer et al. 2021 PRX 11 041050)を追加し、🧶 B1534+12 の 3 行に
  **タイミングモデル(DD・Damour & Deruelle 1986)**と**エポックが未取得であること**を明記した。
  棚卸し `tests/exp-w249b-calaudit.mjs` は 🧶 の σ を読めるようになった(第251便c から CSV には
  あったのに、対応表に行が無くて「σ 無し」に見えていた)。
- **検出器の合成軌道検定**(`tests/exp-w256d-detector.mjs`・QA `behavior.periDetectorSynthetic`):
  真値が閉じた式で分かる軌道では検出器 A/B は真値を **10⁻¹⁰ 台**で復元する。したがって
  シミュレータ側の A−B(4.5×10⁻⁶〜2.9×10⁻⁴ °/周)は**定義差でも推定器誤差でもない**。
- **星団の対照器**(`tests/exp-w256d-cluster.mjs`): C0/C1/Cn を M・r_h・L を揃えて 3 seed・50 交差時間
  走らせた結果、**3 群とも半質量半径が 3.9〜7.5 倍に膨張**し、**複数 BH の Cn が 3 seed すべてで最も速く崩れる**。
- **恒星 4 量 + 📻 の 3 段**(`--dt3`): 「数値未解決 5」が **1** になり、代わりに **合 2 / 否 2** が出た
  (`converged` は 14 → **29** 量)。

## 4′. 第257便d(第49報)で足したもの

- **棚卸しの門を 4 段で読む**(`tests/exp-w249b-calaudit.mjs`): ①数値収束 ②観測量対応 ③観測適合(3σ)
  ④予測。**`definitionMatches` は A を正本にした「定義が宣言されているか」だけになり**、
  検出器 A−B は `orbitNoiseIndicator`(軌道側の相対 1e−10〜1e−8 の雑音に対する検出器差の感度)
  として別欄に出る(第256便d ③ の同定に合わせた命名)。第 4 の状態 **`mapping-unresolved`**
  (観測量対応が未確定 — 例: タイミングの e_T と距離極値の eProxy)を足した。
  **3σ の合否の数は前後で変わっていない(合 2 / 否 2)。**
- **⚡ の ω̇ 行の来歴**: 一次表(Kramer et al. 2021 PRX 11 041050 Table IV・arXiv:2112.06795 p.20・TDB)を
  直接確認した。値・σ は既存の転写と一致し **数字は 1 つも動いていない**。
  **P_b・e_T は Hu et al. (2022) の別解のまま**で、時刻系・エポック・タイミング解は混ぜない。
- **🧶 の dt/4 の計算時間予算を既定 80 s に**(精度条件の緩和ではない)。
- **Float32 質量の記録**: `S.m` は `stateCarry:"double"` の系でも Float32Array である。
  NS 4 系+🎻 の保持質量・最小刻み・宣言値との差と、massCalibration の f の分解能を台帳に入れた。
- **星団の N/ε 掃引**(`tests/exp-w257d-cluster2.mjs`): 初期の 2K/|U|・E_tot・λ・外縁条件を
  3 群で揃えてから N × ソフトニング ε を掃いた(→ PHYSICS〔第257便d〕)。**星団は本 Release の範囲外のまま。**

## 5. 版の切り方(統括への申し送り)

- **名前**(第257便d で確定): 「**v1.44 検証版(RC)— NS 連星までの数値収束・観測一致は主張しない**」。
- **名前の候補**(第256便d の記録): 「**NS 連星までの現実較正(数値収束)**」/「**検証用 beta**」。
  **「現実較正完了」とは書かない**(NS 連星では 3σ の門が 1 件も開いていない。恒星連星で開いた 4 件のうち
  2 件は **DFM 版の「否(3σ)」**である)。
- **root 昇格**: 本便では行わない。昇格するなら `index.html` と `beta/index.html` の差分を
  統括がフルゲートで通してから。`APP_VERSION` も同時に上げる。
- **恒星 4 量(✨✴️🌟💫 の周期)**: 「NS まで完了」を名乗るなら未判定を残さない、という
  ChatGPT の条件への回答は第256便d ④ の実測にある(PHYSICS〔第256便d〕参照)。
  **「数値未解決 5」は「数値未解決 1・合 2・否 2」になった** —— 未判定量は減ったが、
  **減った先の 2 件は DFM 版の 3σ 不合格**である。**この 2 件を先に台帳へ載せずに版を切ってはならない。**
