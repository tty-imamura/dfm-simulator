# 文献の値の照合の手順 —— 「未照合」から「照合済み」へ

- **出どころ**: 原仮定者の回答(2026-11-21 —— 第145報)「AN903: 推奨で進める。別途、照合方法をまとめる」・統括の検証項目 R392(第345便a)。本書の節は `docs/PHYSICS.md`〔第345便a〕。
- **位置づけ**: 手順と記録の様式の文書である。**本書は数を載せない**(文献の値は、それを使う節に「文献の値・未照合」と書いて置いてある —— 本書はその節の名を指すだけ)。本書は物理の主張をしない。照合は「書き写しと算術と定義が出典どおりか」を見る作業で、模型が現実の宇宙と合うかを決める作業ではない(現実の宇宙の主張ではない)。
- **既存の台帳との関係**: 観測の表(`paper/data/` の CSV)が引いている外部データの表の実体は、`paper/data/sources-manifest.json`(第271便b)が台帳である(取得できたバイト列の SHA-256・固定できたかどうか)。本書は、まだデータの表に入っていない**文献の値**(節の比べる列に置いた値)を照合済みにする手順で、その台帳の行は書き換えない。

## 0. 前提 —— この作業環境から外の資料は取りに行かない

1. **この作業環境から、外の資料(論文・表・カーネルの注釈・ウェブの頁)は取りに行かない。** 照合は、資料のファイル(表の抜粋・注釈の該当の行・論文の該当の頁)を**受け取った項目から**行う。
2. 受け取っていない値は、出典の名を書き「文献の値・未照合」と明記して、比べる列にだけ使う。未照合の値で採用・棄却を言い切らない(「この文献の値・この比べる仮定では」の表にする)。
3. ほかの者(人でも道具でも)が「一次資料から読んだ」と言う数も、このリポジトリでは未照合として扱う。その者が自分の環境で測った・読んだという数を、このリポジトリの結果として書かない。

## 1. 手順の 5 段

| 段 | すること | 残すもの | 次へ進まない場合 |
|---|---|---|---|
| ① 出典を固定 | 著者・題・識別子(DOI・配布元の名と版)・表/式/行の番号・取得の日を書く。受け取ったファイルの SHA-256 を、受け取ったバイト列から計算する | 抜粋のファイル(改変しない)と、その SHA-256 | 版が分からない・ほかの者の書き写ししか無い・受け取ったファイルが無い |
| ② 測った量を固定 | 観測した量・単位・符号・時計と座標系・元期・不確かさの種別(統計・系統・相関の有無)を書く。**軌道や解に使った定数の全桁と、公表された推定値 ± 不確かさは、別の行にする** | 量ごとの行(値・単位・σ・値の種別) | 同じ記号で定義が違う・σ が無いのに合否を付けようとしている |
| ③ 写しと算術を作り直す | 受け取ったファイルから値を写し直し、受け取った桁だけで算術を作り直す。**記憶の数や、このリポジトリに前から在る数で置き換えない**(前から在る数は、作り直した数と比べる相手) | 写しと算術の記録(式と入力の桁) | 丸めの順・別の量を含む和・前の測定を使った推定で、差の説明が付かない |
| ④ 比べる約束を先に宣言 | 装置が読む量を、模型の出力から組み立てる式・固定したノブ・比べる仮定を、比べる前に 1 か所に書く | 比べる約束の行(式・ノブ・仮定・使う/保留の理由) | 時計・光学・原子の遷移などをその場で同時に動かして、同じ量で判定しようとしている |
| ⑤ 記録の 3 段を別々に持つ | 下の 2 の 3 段を、それぞれの日付と根拠のファイルつきで別々に記録する | 段ごとの記録 | 3 段を 1 つの印にまとめようとしている |

- **印字の桁は不確かさではない。** 注釈や表に印字された桁の数を σ と読まない(共分散の無い値の σ は空欄)。
- **接触の要素から出した周期を、平均の周期の合格にしない。** 接触の(osculating)要素と、平均の経度の進みから読む平均の周期は別の量。
- **装置が読む量で比べる。** 例: イオンの時計の測定は周波数の積から作る量で、寿命ではない(ミューオンの寿命と混ぜない)。静止の時計の値を、装置が読む量の式に代わりに入れない。
- **2 つの値に同じ名前を付けない。** 例: 個別の重力定数の和と、小さい衛星を含む系の全体の値は別の行。

## 2. 記録の 3 段(別々に持つ)

| 段 | 意味 | 根拠 | このリポジトリでの扱い |
|---|---|---|---|
| (i) 外で写しと算術を見た | このリポジトリの外で、誰かが出典を見て書き写しと算術を見た、という申告 | 申告の文(出典の名・表の番号) | 未照合のまま。比べる列の注に「外の申告あり」と書けるだけで、結果の文には使わない |
| (ii) このリポジトリで照合した | 資料のファイルを受け取り、上の手順 ①〜④ をこのリポジトリで行った | 抜粋のファイルと SHA-256・写しと算術の記録・比べる約束 | 「照合済み」。データの表(`paper/data/`)に行を足せる |
| (iii) 較正に使える | 照合済みに加えて、σ と独立性(同じ解の中の内部の整合ではないこと)が、較正の門に入れられる大きさで在る | (ii) の記録 + σ の種別と独立性の注 | 較正や σ の門に使える。照合済みでも、この段が無ければ較正に使わない |

- (ii) は (i) を前提にしない(外の申告が無くても、ファイルを受け取れば照合できる)。(iii) は (ii) を前提にする。
- 照合済みになった後でも、どの列を主にするかは別に決める(照合は主の列の選びではない)。

## 3. 記録の様式(JSON の欄の例)

1 つの出典に 1 つの記録。値は**受け取った桁のまま文字列で**書く(浮動小数に読み替えない)。下は欄の例で、数は入れていない。

```json
{
  "sourceId": "<出典の短い名>",
  "citation": "<著者・題・誌名と巻と頁・年、または配布元の名と版>",
  "identifier": "<DOI や配布元の識別子>",
  "tableOrLine": "<表・式・行の番号>",
  "retrievedDate": "<取得の日(YYYY-MM-DD)>",
  "excerptFile": "<抜粋のファイルの名>",
  "excerptSha256": "<抜粋のファイルの SHA-256>",
  "frame": "<座標系・中心>",
  "timeScale": "<時刻の尺度>",
  "epoch": "<元期>",
  "entries": [
    { "key": "<量の名>", "value": "<受け取った桁のまま>", "unit": "<単位>", "sigma": null,
      "sigmaKind": "<統計 / 系統 / 合成 / 無し>", "valueType": "adopted_constant", "note": "<解や軌道に使った定数の全桁 —— 印字の桁は σ ではない>" },
    { "key": "<量の名>", "value": "<受け取った桁のまま>", "unit": "<単位>", "sigma": "<受け取った桁のまま>",
      "sigmaKind": "<統計 / 系統 / 合成>", "valueType": "estimated_measurement", "note": "<公表された推定値 ± 不確かさ>" }
  ],
  "assumptions": ["<比べる仮定 —— 例: 崩壊の数は当事者時間に従う・場の枠 = 実験室>"],
  "comparison": "<装置が読む量を模型の出力から組み立てる式・固定したノブ>",
  "stages": {
    "externalCopyChecked": null,
    "repoVerified": null,
    "calibrationUsable": null
  },
  "status": "未照合"
}
```

- `valueType` は `adopted_constant`(解や軌道に使った定数 —— 全桁)と `estimated_measurement`(公表された推定値 ± 不確かさ)の 2 つ。同じ量でも 2 つの種別は別の行にする。
- `sigma` は出典に在るときだけ書く。共分散の無い和や、印字の桁しか無い値は `null`。
- `stages` の 3 つの欄は、上の 2 の (i)(ii)(iii) に対応する(済んだ段に日付と根拠のファイルの名を書く —— 済んでいない段は `null`)。`status` は `未照合` / `照合済み` / `較正に使える` のどれか(`stages` と食い違わせない)。

## 4. 置き場の約束

- **データの表(`paper/data/`)には照合済みの値だけを置く。** 未照合の値は、器の宣言の入力(ノブの列・比べる列)のまま置く。
- 照合の記録(上の 3 の JSON)と抜粋のファイルは、照合済みにする便で、データの表と同じ場所の近くに置く(置き場の名はその便で決める —— 本書では作っていない)。
- 照合済みの値を使う節には、記録の `sourceId` を書く。前から在る未照合の書き方の文は消さない(当時の文として残し、訂正の文を足す)。

## 5. 今の未照合の 3 件(例 —— どれも文献の値・未照合。数は各節に在る)

本書は数を新しく足さない。数は下の節に「文献の値・未照合」として在る。

| 項目 | 節 | ① 出典を固定 | ② 測った量を固定 | ③ 写しと算術 | ④ 比べる約束 | (i) 外で見た | (ii) このリポジトリで照合した | (iii) 較正に使える |
|---|---|---|---|---|---|---|---|---|
| イオンの時計の測定(蓄積リングのイオン・中くらいの速さ) | 〔第344便c〕 | 出典の名だけ(ファイルは受け取っていない) | 節に装置が読む量の式を書いた(周波数の積から作る量) | 節に在る桁での算術だけ(写しは出典と見比べていない) | 節に比べる仮定を書いた | 書かない | 未 | 未 |
| ミューオンの寿命(静止の寿命と蓄積リングの寿命) | 〔第343便c〕 | 出典の名だけ(ファイルは受け取っていない) | 節に寿命の 2 つの量を分けて書いた | 節に在る桁での算術だけ(写しは出典と見比べていない) | 節に比べる仮定を書いた | 書かない | 未 | 未 |
| 冥王星–カロンの重力定数(個別の値・和・系の全体の値) | 〔第344便g〕 | 出典の名だけ(ファイルは受け取っていない) | 節に個別の和と系の全体の値を別の列で書いた | 節に在る桁での算術だけ(写しは出典と見比べていない) | 節に 2 体の比べに使う列を並べた | 書かない | 未 | 未 |

- 「(i) 外で見た」の欄は、このリポジトリの結果として書かない欄なので「書かない」と置いた(外の申告の有無を結果にしない)。
- 3 件とも、照合済みにするには、資料のファイル(表の抜粋・注釈の該当の行)を受け取ってから上の手順 ①〜④ を行う。どれから始めるかは決めていない。

## 6. 書かないこと

- 未照合の数を、照合した数のように書かない(「一次資料と照合した」「出典を固定した」と、ファイルを受け取らずに書かない)。
- 照合済みを、較正に使える・模型が合った、と読み替えない。
- 印字の桁を σ と書かない。同じ解の中の内部の整合を、独立な予測の成功と書かない。
