# RELEASE NOTES v1.47 検証版(RC)

**v1.47 は検証版(RC)である。** RC は「検証版」の意味であって、較正の完了でも観測一致の主張でもない。
**3σ の門の数は v1.46 から増えていない**(掲載 122 本の較正 4 値は **合 0 / 量限定合 2 / 否 1 / 保留 16** —— `docs/SAMPLE_STATUS.md`。第318便から版なしの名 —— 第343便から同じ 4 値)。
**HOLD 6 項の解除宣言は行っていない**(`docs/RELEASE_NOTES_v1.44.md` §4⁶″ をそのまま継ぐ —— 継承は再判定ではない)。
したがってこの版も「**現実較正を完了した**」「**Release した**」とは名乗らない。開発線で足した診断は、どれも**候補を並べた表**であって、採る型の結論ではない。
